Jarvis · 贾维斯 —— 安装前请先读这 7 条
==================================================

1. 项目自签名（不是权威 CA 签名，SmartScreen 仍可能提示）
   本安装包使用项目自签名证书（签名者：CN=贾维斯, O=Jarvis, C=CN）：
     - 运行与安装包同目录的信任脚本后，文件属性里能看到签名者，签名状态为「有效」；
     - 但按微软口径，自签名在 SmartScreen 上等同未签名：双击安装包，或从网盘、
       U 盘、聊天工具转存后再打开，仍可能出现「Windows 已保护你的电脑」或
       「未知发布者」提示。
   继续方法：点提示里的「更多信息」，再点「仍要运行」。
   首次安装出现「未知发布者」是预期行为，不是安装包损坏或被篡改。
   想避免这个提示，可先运行与安装包放在同一目录的「信任签名证书.cmd」
   （只信任当前 Windows 用户，不需要管理员权限），再双击安装包；
   不导入信任也可以按上面的方法直接安装。
   导入信任只在这台电脑的当前用户下生效，不等于「已验证发布者」的公开信任，
   换一台电脑或换一个 Windows 账户后，提示仍可能出现。
   这不代表文件有问题；请只从你信任的来源获取，并以发布页给出的 SHA256 为准。
   后续版本签名会改变文件字节与 SHA256，届时请以新发布页给出的值为准。

2. 默认装到 D 盘，程序与数据分开
   程序安装到：D:\Jarvis
   用户数据在：D:\LiuHaoData（不在程序目录里，卸载默认不会带走账号与 Key；
   Key 以加密形式存放，不是明文）
   如果 D 盘不可用（不存在 / 不可写 / 是可移动盘）：
     - 程序目录自动回退：%LOCALAPPDATA%\Programs\Jarvis（当前用户目录，不需要管理员
       权限、不弹 UAC）；主动「以管理员身份运行」时回退到 C:\Program Files\Jarvis。
     - 数据目录：安装向导会停下来让你确认 / 改选，D 盘不可用时通常预填
       %LOCALAPPDATA%\LiuHao\data。没有检测到可用非系统盘时，数据目录和备份目录
       都自动落到 %LOCALAPPDATA%\LiuHao，安装继续、不会中断；向导会提示
       「没有检测到非系统盘，数据与备份都在 C 盘，建议预留空间」。
       也可以手动改选非系统盘目录（例如 E:\LiuHaoData）。
   回退时安装向导的「准备安装」页会写明实际装到了哪里、为什么回退；
   回退安装还会在程序目录留一份「安装位置说明.txt」，随时可以翻回来看。
   升级备份目录：默认 <数据目录所在盘>:\LiuHaoBackups（数据在 D 盘时就是
   D:\LiuHaoBackups；由安装器显式下发，不占 C 盘，也不会退回数据目录）。
   没有可用非系统盘时，备份目录随数据目录一起落到 %LOCALAPPDATA%\LiuHao。
   这个目录只放升级前的自动备份，不是你的数据备份。
   命令行安装可用 /BACKUPS=<目录> 指定备份目录；显式指定的数据目录与
   /BACKUPS= 都优先于上面的默认推导。
   注意：备份与数据在同一块盘。磁盘损坏、分区丢失或勒索加密时备份会一起丢，
   无法用来恢复数据——这不是异地备份。要防灾请自行再复制一份到移动硬盘或另一台电脑。
   手动备份方法：退出贾维斯后，把整个数据目录复制到移动硬盘或另一台电脑。
   必须同时复制 data\model_config.key 与 data\model_registry.sqlite3；
   少一个，已经保存的 API Key 就解不开。
   如果以管理员身份运行安装包且机器上确实有 C 盘 Program Files 写权限，
   回退目标则是 C:\Program Files\Jarvis（这种情况才会用到管理员权限）。
   已经装在 C 盘的老用户：覆盖安装/升级保持原路径不变，不会被新默认值改走。

3. 安装包不包含任何 AI 模型，没有 Key 也能装
   为控制体积与许可证合规，本包不含 Ollama、GGUF 或任何模型权重。
   首次启动向导会给你三种选择：
     a) 使用本机 Ollama —— 到 https://ollama.com 下载安装，并在命令行执行
        ollama pull qwen2.5:7b（约 2GB）；使用期间请保持 Ollama 在运行。
     b) 使用 OpenAI 兼容云 —— 填接口地址（base_url）、模型名和你的 API Key。
     c) 跳过 —— 没有 API Key 也可以先安装、先启动，模型之后再配。
   选 b 时 API Key 会用 AES-256-GCM 加密后存在数据目录，不会以明文写进配置。

4. 哪些内容会上网、哪些不会
   默认不主动联网。只有部署方配置了云端模型、部署时显式设置了云端向量化，或在设置里
   显式开启「联网检索」后，才会发生传输：
     · 会发到模型服务商：你的对话内容，以及为回答而检索到的知识库片段（作为上下文）。
     · 云端向量化没有界面开关：只有部署时设置 LIUHAO_EMBEDDING_PROVIDER 与对应
       凭据/地址，知识库入库文本才会发给该服务商。环境里存在 OPENAI_API_KEY 不会自动
       让向量化改走云端（默认 auto 只探测本机 Ollama）。
     · 联网检索（默认关闭）：开启后只发送提炼后的检索关键词（最多 48 个字符，并先去掉
       邮箱、电话、密钥和链接），目标固定为三个公开接口：
         hn.algolia.com、api.github.com、export.arxiv.org。
       只发送提炼后的关键词；不发送你的对话内容、对话历史、个人画像、账号信息或 API Key。
       开关位置：控制台「设置 → 隐私与联网」，可随时关闭；关闭后立即生效，无需重启。
     · 不会发到模型服务商：API Key（只保存在本机数据目录，AES-256-GCM 加密）、
       账号密码、审计记录，以及本机的对话/知识数据库文件本身。
     · 本机 Ollama 模式：模型推理只连 127.0.0.1:11434，不出本机。
       注意：如果你显式开启了「联网检索」，检索关键词仍会发到上面那三个公开站点。
   不收集使用统计、不做遥测上报；没有配置更新源时也不会主动检查更新。
   升级信任（公钥 / 清单地址）与备份根所需的用户环境变量由安装器写入当前用户环境，
   装完不需要手工设置任何环境变量。若本次发布没有下发清单地址与公钥（当前版本即如此），
   「检查更新」会如实提示未配置更新源，这是预期行为，不是故障。
   运维可选功能默认全部关闭：漏洞情报（api.osv.dev / api.github.com）、升级清单、
   RFC3161 时间戳、告警 Webhook 都需要显式配置才会请求；第三方集成与 MCP Server
   只有你主动连接后才会访问对应域名。
   加密边界：只有 API Key 加密；对话、知识库、审计等是本地明文 SQLite 文件，
   依靠 Windows 账号权限保护。多人共用或设备可能丢失时，建议开启 BitLocker。
   多个 Windows 账户共用同一台电脑时，数据与密钥不按用户隔离。

5. 安装包里没有任何密钥
   构建过程剔除了 config/auth_secrets.json、human_identities.json、
   外部锚私钥与容器环境配置。你的账号和密钥都是在你自己机器上首次生成的。

6. 卸载默认保留你的数据
   卸载时会问一次「是否同时删除数据」，默认「否」。
   只有你连续两次确认，才会永久删除数据目录（按 data-dir.txt 记录的实际位置，
   也就是 D:\LiuHaoData 或回退后的数据目录，不是写死的 C 盘路径）。
   覆盖安装（升级）不会碰数据目录。

7. 去哪里申请 API Key
   DeepSeek（本次向导默认示例）：
     1) 打开 https://platform.deepseek.com 注册并登录；
     2) 在「API Keys」页创建 Key，复制形如 sk-... 的字符串（按量计费）；
     3) 向导里填：
          接口地址（base_url）= https://api.deepseek.com/v1
          模型名       = deepseek-chat
          API Key      = 你刚复制的 sk-...
   其他 OpenAI 兼容服务同理：在对应平台的「API Key / 密钥」页创建，
   接口地址（base_url）和模型名以该平台文档为准。
   没有 Key 也可以跳过：安装完成后随时到「系统设置 → 模型管理」补上，
   不需要重装，也不需要重跑安装程序。

安装完成后会按你的勾选决定是否立即启动。
首次启动会打开图形化设置向导；没有桌面会话时会回退到命令行向导：
  1) 向导会建管理员账号（默认 liuhao）和登录密码，请记下来；
  2) 向导第 1 步会显示实际数据目录，并写明加密、备份与卸载规则；
  3) 向导结束后服务继续启动，会打开原生控制台窗口（网页模式 --web 才用浏览器），
    地址 http://127.0.0.1:8080（端口默认 8080。首启向导里可以换端口；日常启动
     如果端口被占，窗口会告诉你占用原因并给出处理办法：关掉占用程序再试，
     或在启动入口填一个空闲端口后重新启动）；纯命令行 / 无桌面时
     不会弹窗，而是逐行打印「处理一/处理二」，复制「处理二」那条命令（含引号）重跑，
     退出码 2 表示没有启动；窗口没自动出现时，
     先看托盘图标，或把该地址手动复制到浏览器；
  4) 在登录页用刚才建的账号和密码登录；
  5) 登录后落在「总览」，聊天入口在左侧「自由对话」→「直接对话」。
程序启动后常驻托盘：关掉状态窗口只是隐藏到托盘，网关继续运行，不会停服；
真正退出请用托盘右键菜单的「退出」（「停止服务」只停网关、托盘保留）。
需要命令行模式（排障用）时，在程序目录运行 LiuHao.bat --console。
重开请双击桌面「Jarvis · 贾维斯」快捷方式。
数据与隐私随时可查：登录后点左侧导航底部的「关于与隐私」，可看到版本、数据目录、
许可证、第三方组件声明与联网说明。
第三方软件许可证：安装目录包含 THIRD-PARTY-NOTICES.txt 与 licenses\ 目录（第三方组件全文）；
登录后也可在「关于与隐私」里查看同一份清单。
