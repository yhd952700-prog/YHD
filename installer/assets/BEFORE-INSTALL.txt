鎏灏 LiuHao AI OS —— 安装前请先读这 5 条
==================================================

1. 没有代码签名
   本安装包未做代码签名，Windows 会显示「未知发布者」。
   这是预期行为，选择「更多信息 → 仍要运行」即可。
   正式发布前会补签名证书；当前版本请只从你信任的来源获取。

2. 不需要管理员权限
   程序安装到：%LOCALAPPDATA%\LiuHao\app
   用户数据在：%LOCALAPPDATA%\LiuHao\data
   不会写入系统目录，也不会修改系统环境变量。

3. 安装包不包含任何 AI 模型
   为控制体积与许可证合规，本包**不含** Ollama、GGUF 或任何模型权重。
   首次启动向导会让你二选一：
     a) 使用本机 Ollama —— 需自行安装 Ollama，并至少拉取一个模型（约 2GB）；
     b) 使用 OpenAI 兼容云 —— 填 base_url、模型名和你的 API Key。
   选 b 时 API Key 会用 AES-256-GCM 加密后存在数据目录，不会以明文写进配置。

4. 安装包里没有任何密钥
   构建过程剔除了 config/auth_secrets.json、human_identities.json、
   外部锚私钥与容器环境配置。你的账号和密钥都是在你自己机器上首次生成的。

5. 卸载默认保留你的数据
   卸载时会问一次「是否同时删除数据」，默认「否」。
   只有你连续两次确认，才会永久删除数据目录。
   覆盖安装（升级）不会碰数据目录。

安装完成后会按你的勾选决定是否立即启动。
首次启动是命令行窗口：先走向导，成功后浏览器会自动打开 http://127.0.0.1:8080 。
