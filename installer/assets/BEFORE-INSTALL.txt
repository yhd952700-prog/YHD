鎏灏 LiuHao AI OS —— 安装前请先读这 6 条
==================================================

1. 没有代码签名（预期行为，不是病毒提示）
   本安装包尚未做代码签名，因此：
     - 双击安装包时，Windows 可能弹出「Windows 已保护你的电脑」或
       「未知发布者」提示；
     - 从网盘、U 盘或聊天工具转存后再打开，也可能出现同样的提示。
   继续方法：点提示里的「更多信息」，再点「仍要运行」。
   这只是因为安装包没有购买签名证书，不代表文件有问题；
   当前版本请只从你信任的来源获取。
   后续版本会提供已签名的新安装包（签名会改变文件字节与 SHA256，
   届时请以新发布页给出的值为准）。

2. 默认装到 D 盘，程序与数据分开
   程序安装到：D:\LiuHao
   用户数据在：D:\LiuHaoData（不在程序目录里，卸载程序不会带走账号与 Key）
   如果 D 盘不可用（不存在 / 不可写 / 是可移动盘），会自动回退，不会中断安装：
     程序 → %LOCALAPPDATA%\Programs\LiuHao（当前用户目录，不需要管理员权限、不弹 UAC）
     数据 → %LOCALAPPDATA%\LiuHao\data
   回退时安装向导的「准备安装」页会写明实际装到了哪里、为什么回退；
   装完后程序目录下还会留一份「安装位置说明.txt」，随时可以翻回来看。
   如果以管理员身份运行安装包且机器上确实有 C 盘 Program Files 写权限，
   回退目标则是 C:\Program Files\LiuHao（这种情况才会用到管理员权限）。
   已经装在 C 盘的老用户：覆盖安装/升级保持原路径不变，不会被新默认值改走。

3. 安装包不包含任何 AI 模型，没有 Key 也能装
   为控制体积与许可证合规，本包不含 Ollama、GGUF 或任何模型权重。
   首次启动向导会给你三种选择：
     a) 使用本机 Ollama —— 到 https://ollama.com 下载安装，并在命令行执行
        ollama pull qwen2.5:7b（约 2GB）；使用期间请保持 Ollama 在运行。
     b) 使用 OpenAI 兼容云 —— 填 base_url、模型名和你的 API Key。
     c) 0) 跳过 —— 没有 API Key 也可以先安装、先启动，模型之后再配。
   选 b 时 API Key 会用 AES-256-GCM 加密后存在数据目录，不会以明文写进配置。

4. 安装包里没有任何密钥
   构建过程剔除了 config/auth_secrets.json、human_identities.json、
   外部锚私钥与容器环境配置。你的账号和密钥都是在你自己机器上首次生成的。

5. 卸载默认保留你的数据
   卸载时会问一次「是否同时删除数据」，默认「否」。
   只有你连续两次确认，才会永久删除数据目录（按 data-dir.txt 记录的实际位置，
   也就是 D:\LiuHaoData 或回退后的数据目录，不是写死的 C 盘路径）。
   覆盖安装（升级）不会碰数据目录。

6. 去哪里申请 API Key
   DeepSeek（本次向导默认示例）：
     1) 打开 https://platform.deepseek.com 注册并登录；
     2) 在「API Keys」页创建 Key，复制形如 sk-... 的字符串（按量计费）；
     3) 向导里填：
          API base_url = https://api.deepseek.com/v1
          模型名       = deepseek-chat
          API Key      = 你刚复制的 sk-...
   其他 OpenAI 兼容服务同理：在对应平台的「API Key / 密钥」页创建，
   base_url 和模型名以该平台文档为准。
   没有 Key 也可以跳过：安装完成后随时到「系统设置 → 模型管理」补上，
   不需要重装，也不需要重跑安装程序。

安装完成后会按你的勾选决定是否立即启动。
首次启动是一个命令行窗口，请先走完向导：
  1) 向导会建管理员账号（默认 liuhao）和登录密码，请记下来；
  2) 向导结束后服务继续启动，浏览器会尝试打开驾驶舱
     http://127.0.0.1:8080（端口被占用时会自动顺延，
     以窗口里打印的「驾驶舱」地址为准）；浏览器没自动打开时，
     把该地址手动复制到浏览器；
  3) 在登录页用刚才建的账号和密码登录；
  4) 登录后落在「总览」，聊天入口在左侧「工作台」→「直接对话」。
运行期间请不要关闭这个命令行窗口：关掉窗口就是停止服务；
重开请双击桌面「鎏灏 LiuHao AI OS」快捷方式。
