LiuHao AI OS · 鎏灏智能中枢 —— LGPL 源码提供清单（iconv / lxml）
========================================================

适用对象
--------
lxml 6.1.3 的 Windows 二进制 wheel 内置 GNU libiconv（LGPL-2.1），
随包文件为 runtime/Lib/site-packages/lxml/etree.cp312-win_amd64.pyd。
本目录同时提供“工作”源码与库源码，供接收方修改 libiconv 后重新链接，
以履行 LGPL-2.1 第 6 条的重链接/源码义务。

1. lxml 6.1.3（“工作”源码）

重链接步骤（可执行方案）
------------------------
1. 解压 lxml-6.1.3.tar.gz 与 libiconv-1.17.tar.gz。
2. 按 lxml 官方构建说明准备 Windows 构建环境（MSVC + libxml2/libxslt 依赖）：
   https://lxml.de/build.html
3. 将 libiconv 构建为静态库（重建 etree.pyd）或 libiconv-2.dll（动态链接）。
   - 静态方案：按 lxml 的 static-deps 流程，将 libiconv 的 import library
     加入 libxml2 链接参数，重建 etree.cp312-win_amd64.pyd。
   - 动态方案（推荐，义务最轻）：将 libiconv-2.dll 与重建后的 etree.pyd 放入
     runtime/Lib/site-packages/lxml/，用户可直接替换 libiconv-2.dll。
4. 用重建产物替换 runtime/Lib/site-packages/lxml/etree.cp312-win_amd64.pyd。
5. 运行安装目录下的 LiuHao.bat 与 lxml 自检，确认 XML/XSLT 功能正常。
