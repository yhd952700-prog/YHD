贾维斯（Jarvis）一键安装版 0.4.1 —— 安装使用说明（一页纸）

这是什么
--------
贾维斯是你的工作台：打开浏览器就能聊天、写东西、管任务。
这个包下载解压后就能用，不用你再装任何东西、不用懂代码。

安装（只做一次）
----------------
1. 下载这个 zip 包：Jarvis-Windows一键安装版-0.4.1.zip。
2. 解压到 D:\Jarvis（直接解压到 D 盘根目录，文件夹名字就是 Jarvis）。
   注意：不要解压到很深的文件夹里（比如桌面上套了好几层的文件夹），
   路径太长会出问题。D:\Jarvis 最好。
3. 打开 D:\Jarvis，双击 start-jarvis.bat。

第一次启动（只做三件事）
--------------------------
双击后会弹出一个黑窗口，按提示做三件事：
1. 建管理员账号：输一个英文账号（比如 liuhao），再输两次登录密码。
   密码输的时候不显示，两次必须一样，空密码不行。
2. 给工作台起名字：直接回车就用默认的「贾维斯」，也可以自己起一个。
3. 选模型：直接回车就跳过。跳过以后不会再追问你。
   登录之后，在控制台「系统设置 → 模型管理」里再配模型。
   没配模型之前，聊天会老实告诉你“没配模型”，不会编假回答。

做完这三件，浏览器会自动打开，地址是 http://127.0.0.1:8080。
用刚才建的管理员账号登录，就能用了。

以后每次使用
--------------
双击 D:\Jarvis 里面的 start-jarvis.bat，等浏览器自动打开就行。
黑窗口不要关：关了贾维斯就停了。可以最小化，不碍事。

不用你做的事
--------------
不用装 Python，不用装 Node，不用联网下载东西，不用敲命令，
不用等它现场安装。第一次启动也不用联网（只有以后真正用云端
模型聊天时，才需要联网）。

如果启动失败
--------------
黑窗口里会写中文原因。把黑窗口最后一段文字复制下来发回来，
我们帮你看。常见原因：
- 提示缺少文件：包没解压全，重新下载、重新解压到 D:\Jarvis。
- 提示端口被占：8080 端口被别的程序占了，先关掉那个程序再试。
- 建账号失败：按黑窗口的提示重输一遍，再双击一次。

你的数据存在哪里
------------------
账号、对话、知识库存在你电脑的 C:\Users\你的用户名\AppData\Local\LiuHao\data，
卸载、重装、换新包都不会删它。想备份，退出后把整个 data 文件夹复制一份就行。
