Jarvis · 贾维斯 —— Windows 安装使用说明（一页纸）
================================================

没有默认账号密码
第一次使用时，程序会让你自己建一个管理员账号（起个用户名、设个密码）。
请记好这个账号密码，之后每次登录都要用它。不要问别人要账号，也没有
通用密码。
第一个建好的账号就是 Owner（最大权限的老板账号）：能看到所有用户的
情况、管理成员和权限。之后别人用的账号只能看到自己的东西。

第一步：解压到哪里
1. 在 D 盘新建一个文件夹，名字叫 Jarvis（完整路径是 D:\Jarvis）。
2. 把这个 zip 包解压到 D:\Jarvis 里面。
3. 解压后打开 D:\Jarvis，应该直接看到 start-liuhao.bat 这个文件。
注意：不要解压到桌面，也不要放在带中文或空格的文件夹里（比如
“新建文件夹”、带你名字的文件夹），否则可能启动失败。

第二步：双击启动
双击 start-liuhao.bat。
会弹出一个黑窗口，不要关它——程序就靠这个窗口运行，用的时候一直
开着它，可以最小化。第一次要等几分钟，黑窗口里会显示正在准备。

第三步：第一次会弹出什么（只在第一次出现）
黑窗口会先请你做三件事，都可以在黑窗口里直接输入：
1. 建管理员账号：起个用户名，设个密码，记好。
2. 给工作台起个名字：顶栏、登录页和助手都显示这个名字；直接回车
就用默认「贾维斯」，以后在控制台「系统设置 → 工作台名字」里可以再改。
3. 选模型（二选一，不会可以先跳过，以后在控制台里再配）：
- Ollama（本地模型）：电脑里要先装好 Ollama，并下载好模型。
- OpenAI 兼容的云模型：需要你自己去模型服务商那里申请一个
API Key，再填进来。Key 只存在你自己电脑的加密数据库里。
先跳过也可以：能正常登录控制台，只是暂时不能聊天——没配好模型
时，贾维斯会老实告诉你还没配置，不会编造回复。

第四步：打开后看到什么
准备好之后，浏览器会自动打开控制台登录页（地址是
http://127.0.0.1:8080 ）。用第三步刚建的管理员账号登录，就能用了。
打开就是贾维斯的操作台：中间是和贾维斯的对话，底部有输入框，
输入框上面是工具箱（总结、写邮件、润色、翻译、想点子、代码示例），
左边是总览、任务、审批这些入口。
以后每次用：双击 start-liuhao.bat，等浏览器自动打开，登录即可。
不用时：关掉黑窗口，程序就停了。

常见问题
1. 提示“没找到 Python”怎么办？
去 python.org 下载 Python 3.12。安装时一定要勾选 Add to PATH
（加到系统路径）这一项，装完后重新双击 start-liuhao.bat。
2. 提示“没找到 Node.js”怎么办？
去 nodejs.org 下载 Node.js LTS（长期支持版），一路点“下一步”
装完，重新双击 start-liuhao.bat。Node.js 只在第一次生成控制
台页面时用到，平时启动不需要它。
3. 第一次是不是要联网？
是。第一次运行时要联网下载运行需要的组件，请保持网络畅通，
耐心等几分钟。以后启动就不用下载了。
4. 浏览器没有自动打开登录页怎么办？
先看黑窗口里的最后一行提示，按提示做，再重新双击一次。
如果黑窗口一闪就没了：重新双击，等它停住，看清提示再关。
还是打不开：把黑窗口里最后一段文字发给技术支持。
5. 能把文件夹搬到别的地方吗？
可以，搬完重新双击 start-liuhao.bat 就行。但不要删除里面
自动生成的.venv 文件夹，删了下次又要重新联网下载。
6. 以后别人用，要怎么给他们开账号？
用你的 Owner 账号登录，在成员管理里邀请或创建账号。别人登
录后只能看到自己的任务和文件，看不到别人的，也改不了你的权限。
