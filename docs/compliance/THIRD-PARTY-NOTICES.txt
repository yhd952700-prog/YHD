LiuHao AI OS · 鎏灏智能中枢 —— 第三方软件许可声明（THIRD-PARTY-NOTICES）
================================================================

本文件随安装包分发，用于列明本产品随包使用的第三方软件、其许可证
类型与许可证文本所在位置。

本文件由构建过程自动生成：包名、版本、许可证与文本位置取自本安装包内
runtime/Lib/site-packages 下各包的 *.dist-info/METADATA 与随包文本，
因此与实装内容一致；手工维护的只有本模板里的说明性文字。第 3 节运行时
组件（OpenSSL、libffi、SQLite、Tcl/Tk、MSVC）的版本为人工核对 PE
VersionInfo 后填写，不随包清单自动变化。

第三方名称与商标（如 Python、OpenSSL、SQLite、Tcl/Tk、Ollama、DeepSeek 等）
仅用于说明来源或兼容性，相关商标归其各自所有者所有，本产品与这些厂商无隶属
或背书关系。

  runtime/Lib/site-packages/*.dist-info/licenses/ 内；运行时二进制、静态链接

### 3.1 LGPL-2.1 内嵌组件专项说明（adodbapi / iconv）

顶层 Python 发行包的许可证声明中**没有** GPL/AGPL/LGPL 类许可证；下面两项是
**嵌入在其它发行包内部**的 LGPL-2.1 组件，单独列示并说明义务处置。

#### 3.1.1 adodbapi 2.6.2.0（pywin32 311 内置）

- **来源**：pywin32 311 的 wheel 内置 `adodbapi` 子包，上游为
  https://github.com/mhammond/pywin32/tree/main/adodbapi 。
- **版本**：2.6.2.0（`adodbapi/adodbapi.py` 中 `__version__ = "2.6.2.0"`）。
- **许可证**：GNU Lesser General Public License v2.1（`adodbapi/license.txt`
  首行即 LGPL v2.1；`setup.py` 声明 `LICENSE='LGPL'`）。
- **随包位置**：`runtime/Lib/site-packages/adodbapi/`，含 19 个 `.py` 源文件、
  `license.txt` 与 `setup.py`。
- **链接形态**：**纯 Python，无二进制，不存在静态链接**。分发内容本身就是
  上游源码（未修改）。
- **合规处置**：LGPL 的“源码可得”义务由随包源码直接满足；完整 LGPL 全文见
  `licenses/adodbapi-LGPL-2.1.txt` 与 `licenses/LGPL-2.1.txt`。本产品未修改
  adodbapi；若接收方修改，直接用随包 `.py` 源码替换即可，无需重链接。
  pywin32 顶层包的 BSD-3-Clause 声明仅覆盖 pywin32 自身，不覆盖本子包。

#### 3.1.2 iconv（lxml 6.1.3 内置，静态链接）

- **来源**：lxml 6.1.3 官方 Windows wheel 内置的 GNU libiconv；上游为
  https://www.gnu.org/software/libiconv/ 。
- **版本**：二进制未标注版本资源。lxml 的 `LICENSES.txt` 只声明
  “**iconv**: LGPL 2.1”。本清单以 **libiconv 1.17** 官方源码包作为对应
  源码基线（SHA256 见 `licenses/LGPL-SOURCE-OFFER.txt`）。
- **许可证**：GNU Lesser General Public License v2.1。
- **随包位置**：静态链接进
  `runtime/Lib/site-packages/lxml/etree.cp312-win_amd64.pyd`；
  随包**不存在** `libiconv-2.dll`。
- **“静态链接”这一事实与证据**：`etree.cp312-win_amd64.pyd` 内含 `libiconv`
  字符串；lxml `LICENSES.txt` 明确声明 wheel 内置 `zlib/iconv/libxml2/libxslt/libexslt`；
  全包检索无 `libiconv*.dll`。据此判定为静态链接。
- **合规处置（可执行方案）**：
  1. 随包 `licenses/LGPL-2.1.txt` 与 `licenses/libiconv-NOTICE.txt`
     （完整 LGPL 全文 + 版权声明）。
  2. 随包 `licenses/LGPL-SOURCE-OFFER.txt`（书面源码要约）：列明
     **lxml 6.1.3 完整源码**与 **libiconv 1.17 完整源码**、官方 URL、
     SHA256、重链接步骤，并承诺自二进制分发之日起至少 3 年提供。
     源码包本体保存在发布侧 `dist/release-gate/lgpl-sources/`
     （`lxml-6.1.3.tar.gz`、`libiconv-1.17.tar.gz`），可随发布交付物一并分发。
  3. **重链接手段**：接收方可按 `LGPL-SOURCE-OFFER.txt` 步骤，用修改后的
     libiconv 重建 `etree.cp312-win_amd64.pyd`；或改用动态链接，把
     `libiconv-2.dll` 放入 `runtime/Lib/site-packages/lxml/` 并替换重建后的
     `etree.pyd`，此后用户可直接替换该 DLL。
  4. 本产品未修改 lxml 或 libiconv 的源码。

> 结论：两项 LGPL-2.1 组件的“许可证全文、源码、可重链接手段”均已随包或
> 以书面要约提供，材料层面已闭环；静态链接方案是否满足 LGPL 第 6 条，
> 最终属法务判断（见合规报告第 8 节）。

## 5. 特别说明与口径

1. pywin32 许可证口径（已复核）：安装包内 pywin32-311.dist-info/METADATA
   的 Classifier 写 “Python Software Foundation License”，但同一个包随附的
   win32/license.txt 实际是 BSD-3-Clause 风格文本（Copyright (c) 1994-2008,
   Mark Hammond; 含 “Neither name of Mark Hammond…” 条款）。两者口径不一致。
   本清单按**随包文本**列示为 BSD-3-Clause，并把该文本复制到
   licenses/pywin32-BSD-3-Clause.txt。若后续版本升级 pywin32 后元数据变更，
   以新版本的随包文本为准。
2. OpenSSL 3.5.8：先前只随包二进制、无许可证全文；现在
   licenses/Apache-2.0.txt 随包，版权声明为
   “Copyright 1998-2026 The OpenSSL Authors. All rights reserved.”
3. libffi：libffi-8.dll 无版本资源，只有 ABI 8 可判；按上游 MIT 文本随包，
   实际构建版本未标注。
4. SQLite 3.53.1：按公版（Public Domain）声明随包。
5. Tcl 8.6.12：Tcl 与 Tk 共用 Tcl/Tk License；license.terms 现在同时出现在
   licenses/ 与 runtime/tcl/tk8.6/。
6. Tix 8.4.3：Tix 为独立第三方 Tcl 扩展，采用 Tix License（BSD 风格）。
   全文已随包 licenses/Tix-License.txt（取自上游 Tix 8.4.3 源码包
   license.terms；CPython 安装树本身不带该文本）。随包二进制位于
   runtime/tcl/tix8.4.3/tix84.dll，产品运行时不加载 Tix。
7. requirements.txt 与随包实装版本的差异（以随包实装为准）：certifi（锁 2026.10.23 / 实装 2026.7.22）、PyJWT（锁 2.15.1 / 实装 2.13.0）。
   本清单由构建过程从 payload 的 *.dist-info 现场生成，不需要人工比对。
8. ws 8.21.3 在控制台 package.json 中声明为运行时依赖，但源码与浏览器产物
   均未检出引用，判断为“声明但未随包”，因此不列入前端清单。
9. 本清单未覆盖 Windows 系统 DLL 与安装器工具（Inno Setup）本身的许可证。
10. mcp / fastmcp-slim：pyproject.toml 里有声明、构建虚环境里也装了，但网关与
    桌面壳的运行路径不 import `src/adapters/mcp/mcp_adapter.py`（该模块是全仓
    唯一引用者，且没有任何调用方），因此它们不按“真实 import 图”进入 payload，
    本清单也不列它们。若将来启用 MCP 适配器，需要同时把它加入随包依赖。
11. 第 3 节第 12–25 项为 CPython / lxml / aiohttp / openai / anthropic 内置或
    静态链接的库，其许可证全文已补齐到 licenses/（expat-MIT.txt、
    zlib-License.txt、libmpdec-BSD-2-Clause.txt、Unicode-License.txt、
    Tix-License.txt）；bzip2 与 libxml2/libxslt 的全文分别位于
    runtime/LICENSE.txt 与 lxml 的 LICENSES.txt。liblzma/XZ Utils 为公版，
    不强制署名。
12. LGPL-2.1 组件：adodbapi（pywin32 311 内置）与 iconv（lxml 6.1.3 内置，
    静态链接）是顶层“限制性许可证 0 个”结论的唯一例外；两者已附全文、源码与
    可重链接方案，详见第 3.1 节。构建门禁会校验这些文本与条目存在，缺失即失败。
