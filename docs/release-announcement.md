## 一句话定位

**Jarvis · 贾维斯** 是一个装在 Windows 电脑上的 AI 员工操作系统（Human-Sovereign Agent Operating System，人类主权自主 AI 员工操作系统）：程序和数据默认留在本机（使用云端模型时，对话内容会发给你选择的云服务商）；模型可以接本地 Ollama，也可以接 OpenAI 兼容的云服务。

## 这一版能做什么

- 在 Windows 10/11 64 位电脑上本机安装；不需要管理员权限，不需要预装 Python。
- 首次启动：弹出「贾维斯首次设置」窗口，创建管理员账号，并可选配置模型（可跳过）。
- 控制台：登录、自由对话、模型管理与连接测试。
- 程序默认装到 `D:\Jarvis`，数据默认保存在本机 `D:\LiuHaoData`（D 盘不可用时程序目录回退到 `%LOCALAPPDATA%\Programs\LiuHao`；没有可用非系统盘（只有 C 盘）时数据回退到 `%LOCALAPPDATA%\LiuHao\data`）；覆盖安装和卸载默认保留数据；老版本用户覆盖安装保持原位置不变。

不在这份清单里的能力，不要在本版发布页上写成“已支持”。

## 三步使用

1. **安装**：双击 `Jarvis-Setup-<版本号>.exe`。Windows 提示“未知发布者 / SmartScreen 已阻止”时，点 **更多信息 → 仍要运行**。保留默认安装位置，完成后启动。
2. **首次设置**：启动后出现「Jarvis · 贾维斯」状态窗口（托盘常驻，关掉状态窗口只是隐藏到托盘），同时弹出 **「贾维斯首次设置」** 窗口，共五步：数据目录（默认 `D:\LiuHaoData`，一般不用改）→ 管理员账号（账号 / 显示名 / 登录密码 / 确认密码，至少 8 位且含字母和数字）→ 选择模型（可跳过；默认“跳过，稍后在「系统设置 → 模型管理」里添加”；也可选本机 Ollama 或云端 API Key）→ 完成前请确认 → 自检结果。第 4 页点 **完成并自检**，第 5 页点 **进入控制台**。**没有 Key 也能装**：第 3 步选跳过即可，之后在模型管理补上。完成后控制台在原生窗口（WebView2）中打开登录页 `http://127.0.0.1:8080`，用刚建的账号登录；网页模式才用 `--web` 开浏览器，没自动出现就检查托盘图标。端口默认 8080：首启向导里可以换端口；日常启动如果端口被占，会告诉你占用原因并给出处理办法（换端口方法见安装说明）。首次设置不发恢复码，登录后到左侧「恢复码」页生成一枚。
3. **发第一条消息**：用刚建的账号登录，登录后落在「总览」，聊天入口在左侧 **自由对话 → 直接对话**；输入一句话，收到回复即跑通。云端模型如果失败，先到 **模型管理 → 测试连接** 看错误码。

## 下载与校验

| 文件 | 说明 | SHA256 |
| --- | --- | --- |
| `Jarvis-Setup-<版本号>.exe` | Windows 安装包 | `<发布时填入>` |
| `SHA256SUMS.txt` | 校验值清单 | `<发布时填入>` |

Windows 校验命令：

```powershell
Get-FileHash .\Jarvis-Setup-<版本号>.exe -Algorithm SHA256
```

把输出和发布页的 SHA256 对比，一致再安装。只从官方发布页或官方网盘下载。

当前安装包**使用项目自签名证书**（实测 `Get-AuthenticodeSignature` = `Valid`，主体 `CN=贾维斯`），但不是公开权威 CA 签发，所以 Windows 仍可能提示“未知发布者”。这是自签名证书的正常现象，不是病毒告警；也因此必须自己核对来源和哈希。

## 已知限制（发布时必须保留）

1. **安装包为项目自签名，未由公开权威 CA 签发。** 首次运行可能仍出现 SmartScreen“未知发布者”，部分杀软可能误报；运行随包「信任签名证书.cmd」可消除本机提示。处理方式见安装说明。
2. **安装包不含任何模型。** 首次使用需要自己安装 Ollama 并拉模型（约 2 GB 起），或填写云端 API Key；**不填 Key 也能安装和启动**，首次设置第 3 步选“跳过”即可，之后在模型管理里补。
3. **启动后常驻托盘。** 双击快捷方式会出现状态窗口和托盘图标；关掉状态窗口只是隐藏到托盘、网关继续运行，退出请用托盘菜单“退出”（“停止服务”只停网关、不关托盘）。需要命令行模式时显式运行 `LiuHao.bat --console`。
4. **默认端口是 `8080`。** **首启向导里可以换端口；日常启动如果端口被占，会告诉你占用原因并给出处理办法**：窗口会写出占用者，可以关掉占用程序再试，或改端口后重新启动，不用改快捷方式参数。
5. **多账号体系只到“成员与角色”这一层。** 控制台左侧有「成员与权限管理」「权限矩阵」「角色模板」入口，可以创建成员并分配角色；主账号 / 子账号之外更细的分层与外部同步未验证，**待确认**。
6. **“管家一句话调度”本版本不作为已支持功能。** 该能力仍在完善中；真实一句话链路已在 2026-11-08 网关级真模型验收中跑通（[acceptance/butler-gateway-acceptance-2026-11-08.json](acceptance/butler-gateway-acceptance-2026-11-08.json) `verdict=PASS`：一句话派活/单独指派/并发/失败如实/结果格式 5 场景全 PASS，goal 带 `goal_id` 与事件序列，见 `docs/ACCEPTANCE-BUTLER-REAL-MODEL.md`）；是否作为下个版本的发布内容，**待确认**。
7. **浏览器 / 桌面键鼠的真实自动化后端本版本不包含。** 当前只有受控的接口与占位实现，不要对外承诺“自动操作电脑”。
8. **升级入口在「系统设置 → 软件更新」卡片。** 未配置更新源时「检查更新」按钮为禁用并写明原因，不会假装“已是最新”；配置了更新源后，可按「检查 → 下载 → 校验 → 应用 → 重启生效 → 回滚」完成。没有配置更新源时，仍可退出程序后运行新版本安装包覆盖安装（数据目录不受影响），装完必须重启程序才生效。升级前建议先备份数据目录。
9. **知识库检索依赖可用的嵌入模型。** 功能仍在完善，真实端到端尚未验证；没有配置时不可用，不要写成“开箱即用”。**待确认**。
10. **界面仍在迭代。** 发布截图以最终安装版本为准；旧截图可能和实际界面有差异。
11. **首次启动流程已按当前界面核对。** 本轮用临时数据目录实跑：控制台建号 → 进入「总览」→ 导航、设置页、恢复码页、备份页逐字比对通过；「贾维斯首次设置」窗口的五步字段按 `first_run_gui.py` 核对。最终安装包发布前仍需用正式包再点一遍（本次走的是源码启动路径，不是 `runtime\python.exe`）。
