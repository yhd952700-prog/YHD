## 一句话定位

**鎏灏 LiuHao AI OS** 是一个装在 Windows 电脑上的 AI 智能体操作系统（Human-Sovereign Agent Operating System，人类主权自主智能体操作系统）：程序和数据默认留在本机（使用云端模型时，对话内容会发给你选择的云服务商）；模型可以接本地 Ollama，也可以接 OpenAI 兼容的云服务。

## 这一版能做什么

- 在 Windows 10/11 64 位电脑上本机安装；不需要管理员权限，不需要预装 Python。
- 首次启动向导：创建管理员账号，选择本地 Ollama 或 OpenAI 兼容云模型。
- 控制台：登录、工作台对话、模型管理与连接测试。
- 数据默认保存在本机 `%LOCALAPPDATA%\LiuHao\data`；覆盖安装和卸载默认保留数据。

不在这份清单里的能力，不要在本版发布页上写成“已支持”。

## 三步使用

1. **安装**：双击 `LiuHao-Setup-<版本号>.exe`。Windows 提示“未知发布者 / SmartScreen 已阻止”时，点 **更多信息 → 仍要运行**。保留默认安装位置，完成后启动。
2. **首次设置**：按向导创建管理员账号，选择模型。选 Ollama 就填本机模型名；选云端就填 `base_url`、模型名和 API Key。完成后浏览器打开 `http://127.0.0.1:8080`；如果端口被占，以启动窗口打印的地址为准。
3. **发第一条消息**：用刚建的账号登录，在工作台输入一句话，收到回复即跑通。云端模型如果失败，先到 **模型管理 → 测试连接** 看错误码。

## 下载与校验

| 文件 | 说明 | SHA256 |
| --- | --- | --- |
| `LiuHao-Setup-<版本号>.exe` | Windows 安装包 | `<发布时填入>` |
| `SHA256SUMS.txt` | 校验值清单 | `<发布时填入>` |

Windows 校验命令：

```powershell
Get-FileHash .\LiuHao-Setup-<版本号>.exe -Algorithm SHA256
```

把输出和发布页的 SHA256 对比，一致再安装。只从官方发布页或官方网盘下载。

当前安装包**未做代码签名**，所以 Windows 会提示“未知发布者”。这是预期提示，不是病毒告警；但也意味着必须自己核对来源和哈希。

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11，64 位 |
| 权限 | 普通用户即可，不需要管理员权限 |

| 浏览器 | 能打开本地网页的现代浏览器（建议 Edge / Chrome） |
| 其他 | 不需要预装 Python、Node.js 或 Docker |

## 已知限制（发布时必须保留）

1. **安装包未做代码签名。** 首次运行会出现 SmartScreen“未知发布者”，部分杀软可能误报。处理方式见安装说明。
2. **安装包不含任何模型。** 首次使用需要自己安装 Ollama 并拉模型（约 2 GB 起），或填写云端 API Key。
3. **启动时有一个命令行窗口。** 关闭这个窗口就是停止服务；从托盘启动则可在托盘退出。
4. **默认端口是 `8080`。** 被占用时程序会自动换端口，以启动窗口打印的地址为准。
5. **多账号（主账号 / 子账号）体系本版本暂不包含。** 仓库里有设计文档，但当前安装版没有成员管理入口；是否在后续版本上线，**待确认**。
6. **“管家一句话调度”本版本不作为已支持功能。** 该能力仍在完善中，真实一句话链路还没有验证；是否作为下个版本的发布内容，**待确认**。
7. **浏览器 / 桌面键鼠的真实自动化后端本版本不包含。** 当前只有受控的接口与占位实现，不要对外承诺“自动操作电脑”。
8. **升级的完整回滚链路还没有在安装版上端到端实跑。** 设置页“检查更新”可用；升级前请先备份 `data`，出问题优先覆盖安装上一版本。**待确认**。
9. **知识库检索依赖可用的嵌入模型。** 功能仍在完善，真实端到端尚未验证；没有配置时不可用，不要写成“开箱即用”。**待确认**。
10. **界面仍在迭代。** 发布截图以最终安装版本为准；旧截图可能和实际界面有差异。
11. **首次启动向导的真实双击、逐字输入流程还没有完整实跑。** 向导提示文案、输入容错和“成功后自动打开浏览器”以最终安装版的实际表现为准，**待确认**。
