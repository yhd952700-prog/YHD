## 一、回植两件（打磨第四轮源码级成果，发布物里缺位）

1. **首启时区确认向导**：源码已有（向导 IANA 下拉、设备时区预选、
   `PUT /v1/a2a/settings` 保存，后端端点在发布物内可用），wb dist 向导无此步。
   A3 目标：新源码向导含时区步，预选逻辑与源码版一致；验收 = 全新数据目录
   首启走完向导后 `GET /v1/a2a/settings` 时区与所选一致。
   现状影响：默认时区与机主当前时区一致，无实际感受差（已向机主披露）。
2. **导出确认范围文案**：发布物导出确认文案少列「工作台/Bot + 企业知识」两类
   （后端导出本体完整，含两类）。A3 目标：确认文案与后端实际导出范围逐项一致；
   验收 = 导出确认弹窗逐项对 `account_backup` 收集口径清单。

## 二、通知单一数据源（走查 B4，V1.5 转入）

现状：铃铛（壳内客户端按实时状态合成）与通知中心页（读 `/v1/events` 内存环形
缓冲、重启即失）两套来源，数字与内容对不齐；V1.5 已做临时缓解（B2 真待办角标、
B3 开发项过滤）。

A3 目标（后端 + 壳侧配套）：
1. 新增后端只读模型 `GET /v1/notifications`：持久化通知记录（机主/开发分级、
   按账号已读态）。
2. 状态派生项（未配模型、待审批等）由后端通知服务按与铃铛相同的状态源物化入表。
3. 开发级项（审计证据链等）只进系统状态与诊断，不进机主信息流。
4. 壳侧铃铛与通知中心页改读同一接口（dist 侧改动，随 A3 处置）。
验收：重启后通知不丢；铃铛数 = 通知中心未读数；造一条待审批时两处同步 +1，
处理后同步归零；开发级项在机主信息流零出现。

## 三、聊天内设置直达卡（走查 §5-6，V1.5 转入）

现状：W5 已给「未配 Key」一条聊天提示加了直达填 Key 钮（主题层上限）。
A3 目标：壳的聊天卡片渲染支持通用「直达设置项」卡片（标题 + 一句说明 +

验收：未配 Key 提问 → 卡片出现 → 跳设置填完 → 回聊天原问题已回填可直接发送。

## 四、知识库模型下载入口（V6 转入）

现状：本地语义引擎模型（bge-small-zh-v1.5，约 95MB）不随包，用户首用需显式
下载；状态面已能如实显示未下载原因，但控制台没有下载入口按钮（V6 未动 UI）。
A3 目标：知识中心（或设置的知识区）提供「下载本地模型」入口：显大小、进度、
失败人话原因；下载走已登记的出站白名单。季末打包口径：`knowledge` extra 与
voice extra 同口径装包，模型文件不随包。
验收：断网/无模型状态下入口可见且原因属实；确认后下载完成、知识检索转语义模式。
