# Jarvis 0.4.0 改动说明（分支 jarvis-0.4.0）

本分支基于 `release-0.3.0`（`d077e1cf`），是 2026-11-12 两轮完善后的完整代码。
原版分支 `release-0.3.0` 不动；本分支是最新版。

## 产品

- 改名：鎏灏 / LiuHao AI OS → **Jarvis · 贾维斯**。工作台名字可改：首次启动向导
  与「系统设置 → 工作台名字」里可改，存在后端配置里，全站只读这一个来源
  （`GET/PUT /v1/workspace/name`），默认贾维斯。
- 控制台改成聊天操作台：登录后默认就是和贾维斯的对话（底部输入框，输入框
  上方是工具箱：总结、写邮件、润色、翻译、想点子、代码示例），左边保留原有
  全部页面入口（总览、管家、任务中心、技能中心、工具中心、文件、目标、项目、
  应用、知识、审批、审计、设置）。
- 助手只有一个结合版：Muse 的能力 + 小龙虾的活泼亲切风格，没有 Muse/小龙虾
  切换器，没有可切换的人格分支。
- 权限：第一个建好的账号就是 Owner（最大权限），能看到所有用户的情况、管理
  成员与权限、看审计日志；普通用户只能看到自己的东西。

## 诚实性（不再编数字、不再编回复）

- 健康检查、知识库、成本、插件、组织等处的写死假数字已清掉：默认空态，读不
  到就显示暂无数据；演示数据只在 `LIUHAO_DEMO_SEED=1` 时出现。
- 未配置模型时，聊天明确返回“还没有配置模型，请先配置模型密钥”，绝不编造
  回复；MockProvider 只在演示模式下返回带 `[演示数据]` 的提示。
- 任务执行未接通时返回 501，不再假装执行到 10%。

## 可靠性与工程

- 登录加 30 秒超时（前后端对齐）：超时返回“登录超时，请重试”，不再无限挂起。
- Dockerfile 重构（补齐 COPY 白名单并安装包本身）；Python 统一为 3.12，
  Postgres 统一版本；`.env.example` 补到 92 个变量。
- 旧测试按修好后的诚实行为更新；审批、审计、备份等高风险页面补了测试。
- 发布门禁 `verify_readiness.py --full` 已接入 CI（`.github/workflows/
  release-readiness.yml`，触发分支含 `jarvis-0.4.0`）。

## 怎么跑（Windows）

下载 `Jarvis-Windows一键包.zip`，解压到 `D:\Jarvis`，双击
`start-liuhao.bat`，首次按向导建 Owner 账号、起工作台名字、选模型，
浏览器自动打开 `http://127.0.0.1:8080`。详见包内 `README-安装使用.txt`。
首次使用需自装 Python 3.12、联网下载依赖；没有默认账号密码。
