# 常见问题解答 (FAQ)

本文档收集了 LiuHao AI OS 用户最常问的问题和解答。

---

## 通用问题

### Q: LiuHao AI OS 是什么？

**A**: LiuHao AI OS（鎏灏 X）是一个人类主权自主智能体操作系统（Human-Sovereign Agent Operating System）。它提供构建、运行和管理 AI 智能体的完整平台，支持多智能体协作、记忆系统、规划引擎等核心能力。

### Q: 它和其他 AI 框架有什么区别？

**A**: 主要区别在于：

1. **操作系统级别**：LiuHao AI OS 是一个完整的操作系统级平台，而不只是一个框架
2. **14 个内核架构**：内置身份、记忆、策略、执行等 14 个核心内核
3. **人类主权**：以人类主权为核心设计原则，安全和可控性优先
4. **多智能体协作**：原生支持多智能体协作模式
5. **内置安全和审计**：内核级安全，设计为不可篡改的审计链（运行时完整性当前 UNVERIFIED，见 HC-01）

### Q: LiuHao AI OS 是开源的吗？

**A**: 是的，LiuHao AI OS 采用开源许可证发布。你可以在 GitHub 上获取源代码，自由使用、修改和分发。

### Q: 支持哪些编程语言？

**A**: 核心使用 Python 开发，但提供多语言 SDK：
- Python SDK（官方，功能最全）
- JavaScript/TypeScript SDK
- Go SDK
- Java SDK（Beta）

### Q: 可以在本地运行吗？需要联网吗？

**A**: 完全可以在本地运行。使用 Ollama 本地模型时，所有推理都在本地完成，不需要联网。系统默认配置就是本地优先的设计。

## 技术问题

### Q: 最低系统要求是什么？

**A**: 最低配置：
- Python 3.11+
- 8 GB RAM
- 5 GB 磁盘空间
- 支持 AVX2 的 CPU

推荐配置：
- 16 GB+ RAM
- 20 GB+ SSD
- NVIDIA GPU（8GB+ VRAM，加速本地模型）

### Q: 支持哪些 LLM 模型？

**A**: 支持所有 OpenAI 兼容 API 的模型，包括：
- 本地模型：Ollama 支持的所有模型（Qwen、Llama、Mistral 等）
- 云端模型：OpenAI、Anthropic、通义千问、文心一言等
- 本地优先：默认使用 Ollama 本地模型

### Q: 数据库有什么要求？

**A**: 默认使用 SQLite，零配置即可运行。生产环境推荐使用 PostgreSQL 15+，支持更好的性能和并发。

### Q: 可以使用自己的向量数据库吗？

**A**: 可以。LiuHao AI OS 的记忆系统支持可插拔后端，目前内置 SQLite 和 PostgreSQL 支持，可以通过插件扩展支持其他向量数据库（如 Milvus、Qdrant、Weaviate 等）。

### Q: 智能体的记忆存在哪里？

**A**: 记忆存储在记忆内核中，支持多种后端：
- 默认：SQLite 数据库（文件存储）
- 可选：PostgreSQL
- 工作记忆在内存中，持久化记忆写入数据库
- 语义记忆使用向量索引加速检索

### Q: 支持多用户吗？

**A**: 支持。LiuHao AI OS 内置身份和权限系统，支持多用户、多角色，以及 L0-L7 的作用域级别。

### Q: 如何备份数据？

**A**: 有几种备份方式：
1. 使用内置的备份工具：`liuhao backup create`
2. 直接备份数据库文件（SQLite 模式）
3. 使用数据库的原生备份工具（PostgreSQL 模式）
4. 配置定期自动备份

## 故障排除

### Q: 启动时报错 "Failed to connect to Ollama"

**A**: 请按以下步骤排查：

1. 确认 Ollama 已安装并正在运行：`ollama serve`
2. 确认模型已下载：`ollama list`
3. 检查 `OLLAMA_BASE_URL` 配置是否正确
4. 如果 Ollama 在另一台机器上，确保网络可达

### Q: 智能体回复很慢怎么办？

**A**: 可能的原因和解决方案：

1. **模型太大**：换用更小的模型（如 qwen2.5:3b 代替 qwen2.5:14b）
2. **本地 CPU 推理**：使用 GPU 加速
3. **网络延迟**：云端模型检查网络连接
4. **上下文太长**：优化上下文长度
5. **工具调用太多**：减少不必要的工具调用

### Q: 记忆搜索结果不准确怎么办？

**A**: 可以从以下方面优化：

1. 调整相似度阈值（降低阈值返回更多结果）
2. 使用混合搜索模式（关键词 + 向量）
3. 优化记忆内容的质量和描述
4. 增加记忆的标签和分类
5. 检查嵌入模型是否适合你的语言

### Q: 智能体忘记了之前的对话怎么办？

**A**: 这可能是因为：

1. 记忆没有正确保存 — 检查记忆系统配置
2. 记忆被衰减了 — 重要内容提高重要性评分
3. 搜索没搜到 — 使用更准确的搜索词，或降低阈值
4. 作用域不匹配 — 确认记忆的作用域级别正确

## 定价与计费

### Q: LiuHao AI OS 是免费的吗？

**A**: 社区版是完全免费的开源软件。如果你使用本地模型（Ollama），则没有任何使用费用。如果使用云端 API 模型，则需要支付相应的 API 调用费用（直接付给模型提供商，LiuHao AI OS 不收取中间费用）。

### Q: 有企业版吗？

**A**: 有企业版，提供额外的企业级功能和支持：
- 企业级安全和合规
- 专业技术支持
- SLA 保障
- 定制化开发
- 部署和运维服务

### Q: 如何计算使用成本？

**A**: 成本主要来自：
1. **模型 API 费用**：按 token 计费，取决于使用的模型和调用量
2. **基础设施费用**：服务器、数据库、存储等
3. **LiuHao AI OS 本身**：社区版免费，企业版按订阅收费

你可以在仪表盘的「成本分析」页面查看详细的用量和费用。

## 安全与隐私

### Q: 我的数据安全吗？

**A**: LiuHao AI OS 设计了多层安全防护：
- 数据加密存储（AES-256）
- 传输加密（TLS 1.3）
- 基于角色的访问控制（RBAC + ABAC）
- 完整的审计日志（设计为不可篡改，当前 UNVERIFIED）
- 本地优先设计，数据不离开你的环境

### Q: 智能体会把我的数据发给第三方吗？

**A**: 默认不会。使用本地模型时，所有数据都在你的机器上处理。只有在你明确配置了外部 API 或插件，并授予相应权限时，数据才会发送到第三方服务。

### Q: 支持私有化部署吗？

**A**: 完全支持。LiuHao AI OS 可以完全部署在你的私有环境中，包括本地服务器、私有云或内网。所有数据都在你的控制范围内。

### Q: 如何删除我的数据？

**A**: 你可以随时删除数据：
- 删除特定记忆：通过 API 或 UI 删除
- 删除智能体及其所有记忆：删除智能体时选择删除记忆
- 完全重置：清空数据库
- 用户数据导出：支持导出你的所有数据

### Q: 符合 GDPR 等合规要求吗？

**A**: LiuHao AI OS 的安全设计参考了 GDPR、SOC 2、ISO 27001 等标准，但相关认证均未获得、合规框架未建立（HUMAN DECISION REQUIRED，见 U36/U37/HD-06）；文档中的数据主体权利支持、数据最小化等均为设计对齐特性而非合规认证。具体合规事宜请咨询法务。

## 集成问题

### Q: 可以和现有的系统集成吗？

**A**: 可以。LiuHao AI OS 提供多种集成方式：
- RESTful API
- Webhook
- 插件系统（支持自定义插件）
- MCP 协议
- 预置集成：Slack、飞书、GitHub、Jira、Notion 等

### Q: 支持哪些即时通讯平台？

**A**: 通过插件支持多种平台：
- Slack
- 飞书 / Lark
- 企业微信
- Discord
- Microsoft Teams

### Q: 可以嵌入到我的应用中吗？

**A**: 可以。你可以使用 SDK 或 API 将 LiuHao AI OS 的能力集成到你的应用中，就像使用其他后端服务一样。

### Q: 支持多租户吗？

**A**: 支持。通过作用域系统和组织管理，可以实现多租户隔离，每个租户的数据完全独立。
