## [3.0.0] - 2026-10-01

### 重大变更（Breaking Changes）

- 内核架构从 v2 的模块化架构重构为 14 内核微内核架构
- 记忆系统升级为四层模型（工作/情景/语义/元记忆）
- 作用域系统从 4 级扩展为 8 级（L0-L7）
- API 路径统一为 `/v1/` 前缀
- 配置系统重构，环境变量命名统一

### 新功能

- **14 个内核**：完整的内核架构，包含智能、代理、主权三大类
- **多智能体协作**：支持主从、流水线、委员会、黑板等多种协作模式
- **规划引擎**：多策略规划（LLM、模板、搜索、混合）
- **记忆系统**：四层记忆体系，向量语义检索
- **审计链**：基于哈希链的审计日志（设计为防篡改；运行时完整性当前 UNVERIFIED，见 HC-01）
- **流水线系统**：可视化数据处理流水线
- **插件系统**：可热加载的插件架构
- **信任内核**：智能体信任评分和传播机制
- **评估内核**：任务质量评估和反馈循环
- **驾驶舱**：全新的 Web 控制台界面
- **多语言 SDK**：Python、JavaScript、Go、Java

### 改进

- 性能提升：推理速度提升 2-3 倍
- 内存优化：相同功能内存占用减少 40%
- API 响应时间：P95 延迟降低 50%
- 安装体验：一键启动脚本，零配置运行
- 文档：完整的开发者文档和教程

### 修复

- 修复了记忆系统中的并发访问问题
- 修复了工具调用中的参数传递错误
- 修复了流式输出中的中断恢复问题
- 修复了多个安全漏洞

### 弃用

- v2 API 将在 3.5 版本中移除，建议迁移到 v1 API
- 旧的记忆 API 将在 3.2 版本中移除

## 版本升级指南

### 从 2.x 升级到 3.0

#### 1. 备份数据

```bash
# 备份数据库
liuhao backup create --output backup-2.x.tar.gz

# 备份配置
cp -r config/ config.backup/
```

#### 2. 更新代码

```bash
git pull origin main
pip install -r requirements.txt --upgrade
```

#### 3. 运行数据库迁移

```bash
# Alembic 迁移
alembic upgrade head

# 或使用 CLI
liuhao db migrate
```

#### 4. 更新配置

检查 `.env` 文件，更新为新的环境变量命名：

| 旧变量 | 新变量 |
|--------|--------|
| `MODEL` | `DEFAULT_MODEL` |
| `DB_PATH` | `DATABASE_URL` |
| `DEBUG` | `LOG_LEVEL` |

#### 5. 迁移记忆数据

```bash
# 记忆系统迁移
liuhao memory migrate --from v2 --to v3
```

#### 6. 验证升级

```bash
# 运行健康检查
liuhao health check

# 运行冒烟测试
python scripts/smoke_mvp.py
```

### 从 1.x 升级到 2.0

请先升级到最新的 1.x 版本，然后参考 2.0 升级指南。
