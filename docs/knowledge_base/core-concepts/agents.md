# 智能体（Agent）概念

智能体是 LiuHao AI OS 中的核心执行单元。理解智能体的概念、类型和工作方式，是高效使用 LiuHao AI OS 的基础。

---

## 什么是智能体

智能体（Agent）是一个具有自主决策能力、可以感知环境、执行动作并朝着目标前进的计算实体。

在 LiuHao AI OS 中，智能体具备以下特征：

### 核心特征

1. **自主性**：智能体可以在没有人类持续干预的情况下运行，自主决策和行动
2. **感知能力**：能够感知环境状态、接收用户输入和外部事件
3. **目标导向**：围绕明确的目标或任务展开行动
4. **反应性**：能够对环境变化和新信息做出及时响应
5. **社会性**：能够与其他智能体和人类进行通信协作
6. **记忆能力**：拥有个人记忆空间；从经验中学习的能力当前未实现（NOT_IMPLEMENTED，为规划能力，见 docs/product/PRODUCT-READINESS.md）

### 智能体的组成

```
┌─────────────────────────────────────────────┐
│                  Agent                      │
├──────────┬──────────┬──────────┬───────────┤
│ Identity │  Memory  │  Skills  │  Tools    │
│ (身份)   │  (记忆)  │  (技能)  │  (工具)   │
├──────────┴──────────┴──────────┴───────────┤
│              Reasoning Engine              │
│              (推理引擎)                     │
├─────────────────────────────────────────────┤
│              Planning Engine               │
│              (规划引擎)                     │
├─────────────────────────────────────────────┤
│              Execution Engine              │
│              (执行引擎)                     │
└─────────────────────────────────────────────┘
```

## 智能体类型与角色

LiuHao AI OS 支持多种预定义角色，每种角色有不同的能力倾向和行为模式。

### 内置角色类型

| 角色 | 英文标识 | 核心能力 | 适用场景 |
|------|---------|---------|---------|
| 管理者 | `manager` | 任务分解、协调、决策 | 项目管理、团队协调 |
| 研究员 | `researcher` | 信息检索、分析、综合 | 市场调研、资料收集 |
| 分析师 | `analyst` | 数据分析、洞察提取 | 数据分析、报表生成 |
| 评论员 | `critic` | 质量评估、问题发现 | 代码审查、质量检查 |
| 创作者 | `creator` | 内容生成、创意设计 | 文案写作、创意构思 |
| 执行者 | `executor` | 任务执行、操作完成 | 自动化操作、批量处理 |
| 测试员 | `qa` | 测试设计、缺陷发现 | 软件测试、质量保证 |
| 规划师 | `planner` | 目标分解、路径规划 | 方案设计、路线规划 |
| 通用型 | `general` | 综合能力，均衡发展 | 日常助理、通用任务 |

### 自定义角色

除了内置角色，你还可以通过配置创建自定义角色：

```python
from liuhao import LiuHaoClient

client = LiuHaoClient()

agent = client.agents.create(
    name="财务分析师",
    role="custom",
    config={
        "custom_role": {
            "name": "financial_analyst",
            "skills": ["数据分析", "财务建模", "报告撰写"],
            "personality": "严谨、细致、数据驱动",
            "constraints": ["只处理财务相关数据", "遵守会计准则"]
        }
    }
)
```

## 智能体生命周期

每个智能体都有明确的生命周期阶段：

### 生命周期阶段

```
创建 (Created)
    │
    ▼
初始化 (Initializing)
    │   ├─ 加载身份配置
    │   ├─ 初始化记忆系统
    │   └─ 注册可用工具
    ▼
就绪 (Idle)
    │
    ├─────────────────┐
    │ 收到任务         │
    ▼                  │
运行中 (Running)       │
    │   ├─ 理解目标    │
    │   ├─ 制定计划    │
    │   ├─ 执行动作    │
    │   └─ 评估结果    │
    ▼                  │
暂停 (Paused)          │
    │                  │
    └──────────────────┘
    │
    ▼
停止 (Stopped)
    │
    ▼
销毁 (Destroyed)
```

### 状态说明

| 状态 | 说明 | 可转换到 |
|------|------|---------|
| `created` | 已创建但未初始化 | `initializing` |
| `initializing` | 正在加载配置和资源 | `idle`, `error` |
| `idle` | 空闲，等待任务 | `running` |
| `running` | 正在执行任务 | `idle`, `paused`, `error` |
| `paused` | 已暂停 | `running`, `stopped` |
| `stopped` | 已停止 | `running`（重启） |
| `error` | 发生错误 | `idle`（恢复后） |
| `destroyed` | 已销毁，不可恢复 | - |

## 智能体能力

### 核心能力

1. **自然语言理解与生成**
   - 多语言支持（中文、英文等）
   - 上下文理解
   - 结构化输出

2. **工具使用**
   - 内置工具集（文件操作、网络请求、代码执行等）
   - 自定义工具注册
   - MCP 协议工具集成

3. **推理能力**
   - 链式思考（Chain of Thought）
   - 反思（Reflection）
   - ReAct 模式（Reasoning + Acting）

4. **规划能力**
   - 目标分解
   - 多策略规划
   - 计划验证与优化

5. **记忆能力**
   - 工作记忆
   - 情景记忆
   - 语义记忆
   - 元记忆

### 能力注册与发现

LiuHao AI OS 使用能力注册中心（Capability Registry）管理所有能力：

```python
# 查看智能体可用能力
capabilities = client.agents.get_capabilities(agent_id="agent-abc123")
for cap in capabilities:
    print(f"{cap.name}: {cap.description} (v{cap.version})")
```

## 智能体记忆

每个智能体拥有独立的记忆空间，这是智能体"个性"和"经验"的基础。

### 记忆隔离

- **按智能体隔离**：每个智能体的记忆相互独立，默认不共享
- **按作用域分级**：L0（公开）到 L7（最高机密）共 8 个级别
- **按类型分层**：工作记忆、情景记忆、语义记忆、元记忆

### 记忆访问

```python
# 向智能体记忆中添加内容
client.memory.store(
    agent_id="agent-abc123",
    content="用户喜欢简洁的回答风格",
    memory_type="semantic",
    importance=0.8
)

# 检索相关记忆
results = client.memory.search(
    agent_id="agent-abc123",
    query="用户偏好",
    limit=5
)
```

### 记忆与身份

智能体的身份信息（Identity）存储在身份内核中，是记忆系统的"根"：
- 身份决定了记忆的所有者和访问权限
- 记忆的积累塑造了智能体的"个性"
- 身份可以在多个智能体实例间共享

## 智能体 vs 工具 vs 流水线

这三个概念经常被混淆，以下是它们的区别和关系：

### 对比表

| 维度 | 智能体 (Agent) | 工具 (Tool) | 流水线 (Pipeline) |
|------|---------------|------------|------------------|
| 自主性 | 高（自主决策） | 无（被动调用） | 低（按预定流程） |
| 状态 | 有（记忆、身份） | 无状态 | 有（中间状态） |
| 灵活性 | 高（动态调整） | 低（固定功能） | 中（配置驱动） |
| 适用场景 | 复杂任务、开放式问题 | 单一功能、原子操作 | 数据处理、ETL 流程 |
| 输入输出 | 自然语言为主 | 结构化参数 | 数据流 |

### 它们如何协作

```
用户任务
    │
    ▼
┌─────────┐
│  Agent  │  理解目标、制定计划、协调执行
└────┬────┘
     │ 调用工具
     ▼
┌─────────┐
│  Tools  │  执行具体操作（搜索、计算、读写等）
└────┬────┘
     │ 处理数据
     ▼
┌──────────┐
│ Pipeline │  批量数据处理和转换
└──────────┘
```

### 选择指南

- **选择智能体**：当任务需要理解、决策、适应变化时
- **选择工具**：当你需要一个可复用的功能函数时
- **选择流水线**：当你需要处理结构化数据流时
