# 记忆系统概念

记忆系统是 LiuHao AI OS 的核心组件之一，它使智能体能够积累交互记录、保持上下文一致性。注意：从经验中学习的能力当前未实现（NOT_IMPLEMENTED，为规划能力，见 ../product/PRODUCT-READINESS.md）。本文介绍记忆系统的分层架构、工作原理和核心概念。

---

## 记忆层次结构

LiuHao AI OS 采用四层记忆模型，模拟人类记忆系统的工作方式。

### 四层记忆体系

```
┌─────────────────────────────────────────────────┐
│              工作记忆 (Working Memory)           │  ← 短期 / 活跃
│  容量有限 · 快速访问 · 持续衰减                    │
├─────────────────────────────────────────────────┤
│              情景记忆 (Episodic Memory)          │  ← 中期 / 事件
│  事件序列 · 时间戳记 · 可回放                      │
├─────────────────────────────────────────────────┤
│              语义记忆 (Semantic Memory)          │  ← 长期 / 知识
│  概念事实 · 语义网络 · 向量检索                    │
├─────────────────────────────────────────────────┤
│              元记忆 (Meta Memory)               │  ← 元层 / 自省
│  关于记忆的记忆 · 策略调整 · 自我认知               │
└─────────────────────────────────────────────────┘
```

### 各层记忆对比

| 记忆类型 | 别名 | 存储位置 | 典型容量 | 访问速度 | 生命周期 |
|---------|------|---------|---------|---------|---------|
| 工作记忆 | 短期记忆 | 内存 | 7±2 项 | 极快 (μs) | 秒~分钟 |
| 情景记忆 | 事件记忆 | 内存+持久化 | 数千条 | 快 (ms) | 小时~天 |
| 语义记忆 | 知识记忆 | 向量数据库 | 百万级 | 中 (ms~s) | 持久 |
| 元记忆 | 高阶记忆 | 持久化 | 数万条 | 中 (ms) | 持久 |

## 工作记忆（Working Memory）

工作记忆是智能体当前正在"思考"的内容，相当于"心理草稿本"。

### 工作原理

工作记忆基于 Baddeley 的工作记忆模型，包含：

- **语音环（Phonological Loop）**：处理语言/文字信息
- **视空间模板（Visuospatial Sketchpad）**：处理视觉/空间信息
- **情景缓冲器（Episodic Buffer）**：整合不同来源的信息
- **中央执行器（Central Executive）**：注意力控制器

### 优先级机制

工作记忆容量有限，采用优先级机制管理内容：

| 优先级 | 标识 | 说明 | 权重 |
|--------|------|------|------|
| 关键 | `critical` | 核心目标、活跃任务，必须保留 | 10.0 |
| 高 | `high` | 重要上下文、相关信息 | 5.0 |
| 中 | `medium` | 正常优先级、辅助信息 | 2.0 |
| 低 | `low` | 边缘信息，可能被丢弃 | 1.0 |
| 瞬时 | `fleeting` | 临时信息，立即衰减 | 0.3 |

### 激活与衰减

- 每条记忆项有一个激活值（0-1）
- 访问会提升激活值
- 时间流逝会降低激活值
- 激活值低于阈值的项会被清除

```python
# 工作记忆使用示例
from liuhao.memory import WorkingMemory

wm = WorkingMemory(capacity=20)

# 添加记忆项
wm.add("current_task", "完成季度报告", priority="high")
wm.add("deadline", "2026-10-15", priority="critical")

# 获取最高优先级项
top_items = wm.get_top(n=5)

# 手动触发衰减
wm.decay(elapsed_seconds=300)
```

## 情景记忆（Episodic Memory）

情景记忆存储智能体经历过的事件和对话，是"自传式"记忆。

### 存储内容

- 对话历史（用户消息、智能体回复）
- 任务执行过程（步骤、结果、耗时）
- 重要事件（错误、决策、转折点）
- 交互上下文（时间、地点、参与者）

### 组织结构

情景记忆以**事件序列**的形式组织：

```
Episode (一次会话/任务)
├── Event 1: 用户提问
│   ├── timestamp: 2026-10-07T10:00:00
│   ├── content: "帮我分析销售数据"
│   └── metadata: {source: "user", channel: "web"}
├── Event 2: 智能体思考
│   ├── timestamp: 2026-10-07T10:00:05
│   ├── content: "需要获取销售数据，进行分析"
│   └── metadata: {type: "thought"}
├── Event 3: 工具调用
│   ├── timestamp: 2026-10-07T10:00:10
│   ├── content: "调用 database.query 查询销售表"
│   └── metadata: {tool: "database_query"}
└── Event 4: 智能体回复
    ├── timestamp: 2026-10-07T10:00:30
    ├── content: "销售数据分析结果..."
    └── metadata: {type: "response"}
```

### 检索方式

1. **按时间检索**：获取某个时间段的记忆
2. **按关键词检索**：全文搜索匹配的事件
3. **按语义检索**：向量相似度检索相关经历
4. **按 episode 检索**：获取完整会话上下文

## 语义记忆（Semantic Memory）

语义记忆存储结构化的知识和概念，是智能体的"知识库"。

### 存储内容

- 事实性知识（"北京是中国的首都"）
- 概念关系（"猫是一种哺乳动物"）
- 专业知识（领域知识、技术文档）
- 用户偏好（"用户喜欢简洁的回答"）

### 语义网络

语义记忆以知识图谱的形式组织，包含：

- **实体（Entity）**：人、事、物、概念
- **关系（Relation）**：实体之间的关联
- **属性（Attribute）**：实体的特征

```
用户 ──喜欢──> 简洁风格
  │
  └──使用──> Python
           │
           └──属于──> 编程语言
```

### 向量检索

语义记忆支持向量嵌入检索：

1. 文本内容通过嵌入模型转换为向量
2. 向量存储在向量数据库中
3. 查询时，将查询文本也转换为向量
4. 通过余弦相似度找到最相关的记忆

```python
# 语义记忆检索示例
results = client.memory.search(
    agent_id="agent-abc123",
    query="用户的沟通偏好",
    memory_type="semantic",
    limit=5,
    threshold=0.7  # 相似度阈值
)

for item in results:
    print(f"[{item.score:.2f}] {item.content}")
```

## 元记忆（Meta Memory）

元记忆是"关于记忆的记忆"，即智能体对自己记忆系统的认知和调控。

### 元记忆内容

1. **记忆策略**：什么信息该记住、记在哪一层
2. **遗忘模式**：哪些内容容易遗忘、遗忘速度如何
3. **检索策略**：如何高效找到需要的信息
4. **自我评估**：自己知道什么、不知道什么

### 元记忆的作用

- **注意力分配**：决定关注哪些信息
- **记忆巩固**：决定哪些短期记忆转化为长期记忆
- **检索优化**：根据历史经验优化检索策略
- **元认知**：知道自己的知识边界

## 记忆如何工作

### 记忆写入流程

```
输入信息
    │
    ▼
┌─────────────┐
│  注意力过滤  │  选择性注意，过滤无关信息
└──────┬──────┘
       ▼
┌─────────────┐
│  工作记忆    │  临时存储，活跃处理
└──────┬──────┘
       │
       ├─重要─→ 巩固 ─→ 情景/语义记忆
       │
       └─不重要─→ 衰减 ─→ 遗忘
```

### 记忆检索流程

```
查询请求
    │
    ▼
┌─────────────┐
│  工作记忆    │  快速检查是否在活跃记忆中
└──────┬──────┘
       │未命中
       ▼
┌─────────────┐
│  情景记忆    │  搜索相关事件
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  语义记忆    │  向量相似度检索
└──────┬──────┘
       │
       ▼
结果排序 & 融合
```

## 记忆衰减与巩固

### 记忆衰减

记忆不是永久的，会随时间衰减：

- **工作记忆**：不被关注的项在数秒到数分钟内衰减
- **情景记忆**：随时间推移，细节逐渐模糊
- **语义记忆**：衰减最慢，但长期不访问也会弱化

衰减曲线遵循艾宾浩斯遗忘曲线的近似模型。

### 记忆巩固

重要的记忆会被"巩固"，从短期转移到长期：

1. **重要性评分**：根据内容、用户反馈、访问频率计算重要性
2. **重复访问**：被频繁访问的记忆更可能被巩固
3. **情感权重**：带有强烈情感色彩的记忆更容易巩固
4. **主动复习**：智能体会定期"复习"重要记忆

## 记忆搜索与检索

### 搜索策略

LiuHao AI OS 采用混合搜索策略：

| 策略 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| 关键词搜索 | 精确匹配 | 快速、准确 | 无法处理同义词 |
| 向量搜索 | 语义相关 | 理解语义 | 可能不精确 |
| 混合搜索 | 大多数场景 | 兼顾精度和召回 | 更复杂 |
| 图遍历 | 关系查询 | 发现关联 | 计算量大 |

### 重排序（Reranking）

搜索结果会经过重排序，综合考虑：

- 语义相似度
- 时间新近度
- 重要性评分
- 访问频率
- 上下文相关性

## 记忆最佳实践

### 1. 合理使用记忆层级

- 工作记忆：只放当前任务真正需要的信息
- 情景记忆：记录完整过程，便于回溯
- 语义记忆：存储提炼后的知识和结论
- 元记忆：记录策略性知识

### 2. 设置合适的重要性

- 不要把所有内容都标记为高重要性
- 用户明确表达的偏好应标记为高重要性
- 临时性信息使用默认或低重要性

### 3. 定期清理

- 定期清理不再需要的记忆
- 使用保留策略自动管理生命周期
- 重要记忆定期备份

### 4. 注意隐私安全

- 敏感信息使用高作用域级别
- 遵守数据最小化原则
- 用户有权删除自己的记忆数据
