# 手机端访问与实测记录

> 目标：同一 Wi-Fi 下，手机浏览器能打开控制台、登录、发一条消息。
> 本文只写**实际验证过**的结论；没验证的明确标「未验证」。

## 1. 该用哪个地址（本机实测）

| 网卡 | 地址 | 用途 |
|---|---|---|
| **WLAN** | **`192.168.31.171`** | **手机请用这个**（默认路由也走 WLAN，网关 `192.168.31.1`） |
| vEthernet (WSL) | `172.31.48.1` | 虚拟网卡，手机连不上，**不要用** |
| vEthernet (Default Switch) | `172.25.48.1` | Hyper-V 虚拟网卡，**不要用** |
| 本地连接* 9/10 | `169.254.x.x` | 链路本地地址，**不要用** |
| 蓝牙网络连接 | `169.254.151.38` | **不要用** |

**手机访问地址：`http://192.168.31.171:8000`**（控制台若单独起在 5173 端口，
则控制台地址为 `http://192.168.31.171:5173`，并确保其代理指向本机 8000）。

> 判断方法：`Get-NetRoute -DestinationPrefix "0.0.0.0/0"` 的 InterfaceAlias 是
> `WLAN`，对应的 IPv4 才是手机该用的地址；`172.*` 与 `169.254.*` 一律排除。

## 2. 已验证（服务器侧）

- API 默认绑定 `0.0.0.0`，明确为手机访问设计（`scripts/start_liuhao.py:58`）。
- 实测启动 `uvicorn src.gateway.main:app --host 0.0.0.0 --port 8000` 后：
  - `http://127.0.0.1:8000/health` → **200**
  - `http://192.168.31.171:8000/health` → **200**（即局域网地址可达，不是只听本机回环）

## 4. 身份完整性密钥（已改为启动自举）

历史现象（未自举时的开发库，本机复现）：

```
REFUSING registry row 'liuhao' in 'data/human_identities.sqlite3':
the row does not authenticate against LIUHAO_HUMAN_IDENTITIES_INTEGRITY_KEY
... no human is recognised until then.
```

含义：未设置 `LIUHAO_HUMAN_IDENTITIES_INTEGRITY_KEY` 时，已有的人类身份行
**全部被拒绝**——手机和换机场景会卡在「无人可登录」。

现在的处理（`src/common/integrity_key.py`，安装版与源码启动器都会调用）：

1. **全新安装**：无环境变量、无密钥文件时自动生成 32 字节随机密钥，写到
   数据目录 `config/integrity.key`（不是程序目录、不进安装包）；密钥值不打印。
   权限：POSIX `0600`；Windows 用 `icacls /inheritance:r` 只授予当前用户。
2. **已有数据升级**：登记表里旧版（无 `integrity` 标签）的行会用新密钥补签，
   并打印一行可读说明；旧行从此可被内核接纳。
3. **密钥缺失但身份库仍有已签名行**：不会静默锁死——打印恢复步骤
   （找回旧密钥 / 重新注册管理员），旧行仍按 fail-closed 拒绝，新密钥只用于
   后续注册。

显式设置了环境变量时以环境变量为准，并把它固化到上述文件，避免“环境丢了”
就再次变成无人可登录。回归见 `tests/test_identity_key_bootstrap.py`。

手机侧「打开 → 登录 → 发消息」仍需真机验证，见 §3 与 `docs/known-gaps.md` E-14。

## 5. 防火墙

Windows 默认会拦截入站连接。若手机打不开但本机 200 可达：

- 允许 `python.exe` 的专用网络入站，或放行 TCP 8000；
- 具体命令以 `scripts/` 下的防火墙指引/安装器说明为准（安装器流提供只读指引，
  不自动改防火墙）。

## 6. 复测清单（有手机时照此执行）

1. 手机与电脑连同一 Wi-Fi；
2. 浏览器打开 `http://192.168.31.171:8000`；
3. 登录（使用向导创建的身份）；
4. 新建对话并发一条消息，确认返回非占位内容；
5. 刷新页面确认登录态仍在；
6. 记录失败时的现象：连不上 / 401 / 布局错乱 / 输入法遮挡。
