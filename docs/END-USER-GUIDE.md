# 鎏灏 LiuHao AI OS 使用指南

适用 Windows 10 / 11（64 位）。全程**不需要管理员权限**，安装包**不含任何模型**，也不需要你自己装 Python。

按下面四步走完，就能发出第一条消息。每一步都附了失败时怎么办。

---

## 第 1 步：下载

拿到这两个文件（通常放在同一个下载页）：

- `LiuHao-Setup-<版本号>.exe` —— 安装包，约 34 MB
- `SHA256SUMS.txt` —— 校验值（有就留着，没有可跳过）

把 exe 放到你自己的下载目录即可，不要放在 C 盘根目录或系统目录。

**这一步失败怎么办**

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 浏览器提示“不常用，可能危险” | 安装包未做代码签名 | 点“保留”/“仍要下载”，只从你信任的来源获取 |
| 下载得到一个 `.crdownload` 或文件很小 | 下载中断 | 删掉重下；有 `SHA256SUMS.txt` 就核对大小和校验值 |
| 杀毒软件直接隔离 | 未签名程序的常见误报 | 在杀软里恢复并加入信任；不放心就不要安装 |

---

## 第 2 步：安装并第一次启动

1. 双击 `LiuHao-Setup-<版本号>.exe`。
   - Windows 弹出“未知发布者”：点 **更多信息 → 仍要运行**。这是未签名程序的正常提示。
   - 安装位置默认是 `%LOCALAPPDATA%\LiuHao\app`，不会写入系统目录，也不会弹 UAC。
2. 安装向导弹出时读过说明，直接下一步；建议保留“创建桌面快捷方式”。
3. 安装完成后勾选“立即启动”，或双击桌面上的 **鎏灏 LiuHao AI OS**。

启动后会弹出一个**黑色命令行窗口**，里面是首次运行向导。

> 这个黑窗口就是程序本身，**用的时候不要关**。关掉窗口 = 关闭鎏灏。

**这一步失败怎么办**

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 双击安装包没反应 | SmartScreen 拦截 | 右键 → 属性 → 勾选“解除锁定”，再双击；或按上面的“更多信息 → 仍要运行” |
| 双击快捷方式后窗口一闪就没了 | 安装不完整或上次进程残留 | 重新运行安装包覆盖安装；仍不行看第 2 条“服务没起来” |
| 黑窗口里出现 `[FAIL] ...` 并停住 | 安装目录缺文件 | 重新安装；若提示运行时不完整，说明安装包损坏，重新下载 |
| 黑窗口提示端口被占 | 上次的鎏灏没退干净 | 不用处理，程序会自动换端口，并在窗口里打印 `[warn] ... 已自动改用 NNNN`，浏览器也会打开新端口 |
| Windows 防火墙弹窗 | 程序监听本机地址，首次运行常见 | 勾选“专用网络”并允许；如果你只在同一台电脑上用，点“取消”也不影响本机访问 |

---

## 第 3 步：填 Key（在首次运行向导里完成）

黑色窗口会依次问你两件事。

### 3.1 建管理员账号

- **管理员账号**：英文，例如 `liuhao`（就是以后登录用的账号）
- **显示名**：中文或英文都行，例如 `鎏灏`
- **密码**：输入时屏幕不显示，这是正常的。请记住它。

### 3.2 选择模型来源

向导会让你选：

```
1) Ollama 本地（需先 ollama pull <model>）
2) OpenAI 兼容云（base_url + API Key）
0) 跳过（聊天功能暂不可用，之后在控制台添加）
```

- **选 1（Ollama 本地）**：先装好 Ollama，并至少拉取一个模型（例如 `ollama pull qwen2.5:7b`）。向导会问你模型名和 Ollama 地址，地址一般直接回车用默认的 `http://127.0.0.1:11434`。
- **选 2（OpenAI 兼容云）**：依次填三样：
  - **API base_url**：必须以 `/v1` 结尾。例如 DeepSeek 填 `https://api.deepseek.com/v1`，OpenAI 填 `https://api.openai.com/v1`。
  - **模型名**：填服务商文档里的准确名字。例如 DeepSeek 填 `deepseek-chat`，OpenAI 填 `gpt-4o-mini`。
  - **API Key**：粘贴你的 Key（输入时同样不显示）。Key 会加密保存在本机数据目录，不会明文写进配置文件。

填完后向导结束，浏览器会自动打开驾驶舱（通常是 `http://127.0.0.1:8080`）。

### 3.3 先验证再聊天（强烈建议）

向导**不会**替你验证 Key 是否有效。登录后先做一次连通性测试，比发消息失败后再猜要快得多：

1. 用刚才建的管理员账号和密码登录。
2. 左下角 **系统设置** → 找到 **模型管理**。
3. 在你刚填的模型那一行点 **测试连接**。
4. 看到“连接成功（xxx ms）”就说明 Key、模型名、地址都对了。

测试失败时，界面会直接告诉你该改什么：

| 提示 | 含义 | 怎么办 |
| --- | --- | --- |
| `API Key 无效或没有权限（401/403）` | Key 抄错、已过期、或没有该模型权限 | 重新复制 Key；确认 Key 与服务商匹配；确认账号有余额/权限 |
| `模型名不存在或该端点不支持这个模型（404）` | 模型名拼错，或这个 base_url 下没有这个模型 | 对照服务商文档改模型名；注意大小写和完整前缀 |
| `端点不可达：检查 base_url、端口与网络` | 地址错、少写 `/v1`、网络不通、本机服务没启动 | 检查 base_url；浏览器能打开服务商官网；本地模型确认 Ollama 正在运行 |
| `连接超时` | 网络慢或地址不可达 | 换网络重试；确认地址不是内网/公司代理拦截的地址 |
| `被上游限流（429）` | 请求太频繁或额度用尽 | 稍等再试；检查服务商额度 |
| 选 Ollama 却提示连不上 | Ollama 没启动，或模型没拉取 | 打开 Ollama 应用；在命令行执行 `ollama pull <模型名>` 后再测试 |

> 如果你用的是本机其他 OpenAI 兼容服务（例如 LM Studio），“测试连接”可能被安全策略拒绝；这不影响聊天。直接用第 4 步发消息验证即可。

**选错了想改怎么办？**

登录后到 **系统设置 → 模型管理**，直接编辑模型或新增一个，再点 **设为默认**。不需要重装，也不需要重启。

## 第 4 步：发第一条消息

1. 浏览器打开驾驶舱。如果没自动打开，手动访问 **`http://127.0.0.1:8080`**。
   - 若黑窗口提示端口被占并改成了别的数字，请用窗口里打印的那个地址。
2. 用第 3 步建的管理员账号、密码登录。
3. 左侧点 **工作台**（手机端在底部导航），在输入框里打一句话，例如“你好，介绍一下你自己”，回车发送。
4. 几秒内出现回复，就说明整条链路已经跑通。

**这一步失败怎么办**

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 浏览器显示“无法访问此网站 / 连接被拒绝” | 服务没起来，或黑窗口已被关闭 | 回到黑窗口确认还在运行；已关闭就重新双击桌面快捷方式。仍不行重启电脑后再启动 |
| 浏览器打开的是 `8080`，但页面空白 | 端口被占后程序换了端口 | 看黑窗口里的 `[warn] ... 已自动改用 NNNN`，改用那个端口 |
| 登录提示“未配置（无法登录）” | 向导里没建成管理员（例如密码为空） | 关掉黑窗口，重新双击快捷方式，向导会再次让你建账号 |
| 登录提示“凭据无效” | 账号或密码不对 | 用向导里建的账号；忘记密码只能重新建一个管理员身份 |
| 发消息后回复里出现 `[生成失败]` 和 `401` | API Key 无效 | 按第 3.3 节“测试连接”的 `API Key 无效` 处理 |
| 回复里出现 `[生成失败]` 和 `404` / `model_not_found` | 模型名不对 | 到 **系统设置 → 模型管理** 改正模型名，再点“测试连接” |
| 回复里出现 `[生成失败]` 和 `503` / 连接错误 | 模型服务不可达 | 检查网络、base_url；Ollama 用户确认 Ollama 正在运行 |
| 回复是 `Mock response to: ...` | 当前没有可用的真实模型，系统退回了演示模式 | 到 **系统设置 → 模型管理** 添加模型并 **设为默认**；或重跑向导 |
| 防火墙拦截后手机访问不了 | 只允许了专用网络或根本没允许 | 本机使用不受影响；要手机访问，在“Windows 防火墙 → 允许应用通过防火墙”里放行，并确认手机与电脑在同一 Wi-Fi |

---

## 用完之后

- 关掉黑色命令行窗口即停止服务；下次双击快捷方式重新启动，账号、Key、聊天记录都会保留。
- 数据在 `%LOCALAPPDATA%\LiuHao\data`，覆盖安装/升级不会动它。
- 卸载默认**保留**数据；只有你在卸载时连续两次确认，才会删除账号、Key 和聊天记录。

## 实测等待时间（Windows 11，64 位，本机离线安装）

| 动作 | 实测 |
| --- | --- |
| 安装（约 8600 个文件） | 约 25 秒 |
| 首次启动到页面可用 | 8～15 秒 |
| 向导建账号 + 登记模型（不含你输入的时间） | 9～15 秒 |
| 发送一条消息到收到回复 | 2～3 秒 |
| 关闭后重新启动到页面可用 | 9～16 秒 |

机器性能、杀软扫描、模型服务商的网络延迟都会影响以上数字。超过 1 分钟仍无响应，按第 4 步的“服务没起来”排查。
