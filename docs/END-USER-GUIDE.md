# 鎏灏 LiuHao AI OS 使用指南

适用 Windows 10 / 11（64 位）。全程**不需要管理员权限**，安装包**不含任何模型**，也不需要你自己装 Python。

**没有 API Key 也能装**：向导里选 `0) 跳过` 即可先完成安装和启动，模型之后在
**系统设置 → 模型管理** 里补上。Key 的申请地址见第 3 步。

按下面四步走完，就能发出第一条消息。每一步都附了失败时怎么办。

---

## 第 1 步：下载

拿到这两个文件（通常放在同一个下载页）：

- `LiuHao-Setup-<版本号>.exe` —— 安装包，约 33 MB（33.2 MiB / 34,838,298 字节，为 0.1.0 交付包实测值；每个版本以发布页与 `SHA256SUMS.txt` 为准）
- `SHA256SUMS.txt` —— 校验值（有就留着，没有可跳过）

把 exe 放到你自己的下载目录即可，不要放在 C 盘根目录或系统目录。

**这一步失败怎么办**

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 浏览器提示“不常用，可能危险” | 安装包未做代码签名 | 点“保留”/“仍要下载”，只从你信任的来源获取 |
| 下载得到一个 `.crdownload` 或文件很小 | 下载中断 | 删掉重下；有 `SHA256SUMS.txt` 就核对大小和校验值 |
| 杀毒软件直接隔离 | 未签名程序的常见误报 | 在杀软里恢复并加入信任；不放心就不要安装 |

---

## 第 2 步：安装并第一次启动

1. 双击 `LiuHao-Setup-<版本号>.exe`。
   - Windows 弹出“未知发布者”：点 **更多信息 → 仍要运行**。这是未签名程序的正常提示。
   - 程序默认装到 `D:\LiuHao`，数据默认在 `D:\LiuHaoData`，不写系统目录，也不弹 UAC。
   - D 盘不可用（不存在 / 不可写 / 是可移动盘）时自动回退：
     程序 → `%LOCALAPPDATA%\Programs\LiuHao`，数据 → `%LOCALAPPDATA%\LiuHao\data`。
     回退原因和实际位置会写在安装向导的「准备安装」页，装完后程序目录下还有
     `安装位置说明.txt`。
   - 已经装在 C 盘的老用户：覆盖安装/升级保持原位置不变，不会被新默认值改走。
   - 实际数据目录以程序目录下的 `data-dir.txt` 为准，下面提到 `D:\LiuHaoData`
     的地方都按这个文件的实际内容理解。
2. 安装向导弹出时读过说明，直接下一步；建议保留“创建桌面快捷方式”。
3. 安装完成后勾选“立即启动”，或双击桌面上的 **鎏灏 LiuHao AI OS**。

启动后会弹出一个**黑色命令行窗口**，里面是首次运行向导。

> 这个黑窗口就是程序本身，**用的时候不要关**。关掉窗口 = 关闭鎏灏。

**这一步失败怎么办**

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 双击安装包没反应 | SmartScreen 拦截 | 右键 → 属性 → 勾选“解除锁定”，再双击；或按上面的“更多信息 → 仍要运行” |
| 双击快捷方式后窗口一闪就没了 | 安装不完整或上次进程残留 | 重新运行安装包覆盖安装；仍不行看第 2 条“服务没起来” |
| 黑窗口里出现 `[FAIL] ...` 并停住 | 安装目录缺文件 | 重新安装；若提示运行时不完整，说明安装包损坏，重新下载 |
| 黑窗口提示端口被占 | 上次的鎏灏没退干净 | 不用处理，程序会自动换端口，并在窗口里打印 `[warn] ... 已自动改用 NNNN`，浏览器也会打开新端口 |
| Windows 防火墙弹窗 | 程序监听本机地址，首次运行常见 | 勾选“专用网络”并允许；如果你只在同一台电脑上用，点“取消”也不影响本机访问 |

## 第 3 步：配置模型（可以跳过）

黑色窗口会依次问你两件事。**没有 Key 也能跳过模型配置**，安装和启动都不受影响。

### 3.1 建管理员账号

- **管理员账号**：英文，例如 `liuhao`（就是以后登录用的账号）
- **显示名**：中文或英文都行，例如 `鎏灏`
- **密码**：输入时屏幕不显示，这是正常的。请记住它。

### 3.2 选择模型来源

向导会让你选：

```
1) Ollama 本地（需先安装 Ollama 并执行 ollama pull <model>）
2) OpenAI 兼容云（base_url + API Key）
0) 跳过（聊天功能暂不可用，之后在控制台添加）
```

**去哪里申请 API Key（以 DeepSeek 为例）**

1. 打开 <https://platform.deepseek.com> 注册并登录。
2. 在「API Keys」页创建 Key，复制形如 `sk-...` 的字符串（按量计费）。
3. 向导里填：base_url `https://api.deepseek.com/v1`、模型名 `deepseek-chat`、Key 粘贴上一步的值。

其他 OpenAI 兼容服务同理：到对应平台的「API Key / 密钥」页创建，
base_url 与模型名以该平台文档为准。**没有 Key 就选 `0) 跳过`**，
安装完成后随时到 **系统设置 → 模型管理** 补上，不需要重装或重启安装程序。

- **选 1（Ollama 本地）**：先到 <https://ollama.com> 下载安装 Ollama，并至少拉取一个模型（例如 `ollama pull qwen2.5:7b`，约 2GB）。向导会问你模型名和 Ollama 地址，地址一般直接回车用默认的 `http://127.0.0.1:11434`；使用期间保持 Ollama 在运行。
- **选 2（OpenAI 兼容云）**：依次填三样：
  - **API base_url**：必须以 `/v1` 结尾。例如 DeepSeek 填 `https://api.deepseek.com/v1`，OpenAI 填 `https://api.openai.com/v1`。
  - **模型名**：填服务商文档里的准确名字。例如 DeepSeek 填 `deepseek-chat`，OpenAI 填 `gpt-4o-mini`。
  - **API Key**：粘贴你的 Key（输入时同样不显示）。Key 会加密保存在本机数据目录，不会明文写进配置文件。

填完后向导结束，服务继续启动，浏览器会**尝试**自动打开驾驶舱
（通常是 `http://127.0.0.1:8080`；端口被占用时会顺延，以黑窗口打印的地址为准）。
若浏览器没有自动打开，把该地址手动复制到浏览器即可。

### 3.3 先验证再聊天（强烈建议）

向导**不会**替你验证 Key 是否有效。登录后先做一次连通性测试，比发消息失败后再猜要快得多：

1. 用刚才建的管理员账号和密码登录。
2. 左下角 **系统设置** → 找到 **模型管理**。
3. 在你刚填的模型那一行点 **测试连接**。
4. 看到“连接成功（xxx ms）”就说明 Key、模型名、地址都对了。

测试失败时，界面会直接告诉你该改什么：

| 提示 | 含义 | 怎么办 |
| --- | --- | --- |
| `API Key 无效或没有权限（401/403）` | Key 抄错、已过期、或没有该模型权限 | 重新复制 Key；确认 Key 与服务商匹配；确认账号有余额/权限 |
| `模型名不存在或该端点不支持这个模型（404）` | 模型名拼错，或这个 base_url 下没有这个模型 | 对照服务商文档改模型名；注意大小写和完整前缀 |
| `端点不可达：检查 base_url、端口与网络` | 地址错、少写 `/v1`、网络不通、本机服务没启动 | 检查 base_url；浏览器能打开服务商官网；本地模型确认 Ollama 正在运行 |
| `连接超时` | 网络慢或地址不可达 | 换网络重试；确认地址不是内网/公司代理拦截的地址 |
| `被上游限流（429）` | 请求太频繁或额度用尽 | 稍等再试；检查服务商额度 |
| 选 Ollama 却提示连不上 | Ollama 没启动，或模型没拉取 | 打开 Ollama 应用；在命令行执行 `ollama pull <模型名>` 后再测试 |

> 如果你用的是本机其他 OpenAI 兼容服务（例如 LM Studio），“测试连接”可能被安全策略拒绝；这不影响聊天。直接用第 4 步发消息验证即可。

**选错了想改怎么办？**

登录后到 **系统设置 → 模型管理**，直接编辑模型或新增一个，再点 **设为默认**。不需要重装，也不需要重启。

## 第 4 步：发第一条消息

1. 浏览器打开驾驶舱。如果没自动打开，手动访问 **`http://127.0.0.1:8080`**。
   - 若黑窗口提示端口被占并改成了别的数字，请用窗口里打印的那个地址。
2. 用第 3 步建的管理员账号、密码登录。
3. 左侧点 **工作台**（手机端在底部导航），在输入框里打一句话，例如“你好，介绍一下你自己”，回车发送。
4. 几秒内出现回复，就说明整条链路已经跑通。

**这一步失败怎么办**

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 浏览器显示“无法访问此网站 / 连接被拒绝” | 服务没起来，或黑窗口已被关闭 | 回到黑窗口确认还在运行；已关闭就重新双击桌面快捷方式。仍不行重启电脑后再启动 |
| 浏览器打开的是 `8080`，但页面空白 | 端口被占后程序换了端口 | 看黑窗口里的 `[warn] ... 已自动改用 NNNN`，改用那个端口 |
| 登录提示“未配置（无法登录）” | 向导里没建成管理员（例如密码为空） | 关掉黑窗口，重新双击快捷方式，向导会再次让你建账号 |
| 登录提示“凭据无效” | 账号或密码不对 | 用向导里建的账号；忘记密码见 [faq.md](faq.md) 第 5 节。根账号登录后可在「系统设置 → 恢复码」生成/轮换恢复码；老数据升级上来的账号可在登录页「忘记密码」里用“在本机生成恢复码”补发（码只写入本机数据目录） |
| 发消息后回复里出现 `[生成失败]` 和 `401` | API Key 无效 | 按第 3.3 节“测试连接”的 `API Key 无效` 处理 |
| 回复里出现 `[生成失败]` 和 `404` / `model_not_found` | 模型名不对 | 到 **系统设置 → 模型管理** 改正模型名，再点“测试连接” |
| 回复里出现 `[生成失败]` 和 `503` / 连接错误 | 模型服务不可达 | 检查网络、base_url；Ollama 用户确认 Ollama 正在运行 |
| 回复是 `Mock response to: ...` | 当前没有可用的真实模型，系统退回了演示模式 | 到 **系统设置 → 模型管理** 添加模型并 **设为默认**；或重跑向导 |
| 防火墙拦截后手机访问不了 | 只允许了专用网络或根本没允许 | 本机使用不受影响；要手机访问，在“Windows 防火墙 → 允许应用通过防火墙”里放行，并确认手机与电脑在同一 Wi-Fi |

## 安装与卸载常见问题（Windows）

### 出现“未知发布者 / SmartScreen 已阻止”

安装包当前**没有做代码签名**。Windows 对未签名程序会显示：

- “Windows 已保护你的电脑”
- “未知发布者”

继续安装：

1. 点提示框里的 **更多信息**。
2. 点 **仍要运行**。
3. 安装向导出现后，按提示继续。

这不是“病毒告警”，但也不等于可以无条件信任。只从官方发布页或官方网盘下载；来源不明的安装包不要运行。

如果点了“更多信息”仍没有“仍要运行”：右键安装包 → **属性** → 勾选 **解除锁定** → 再双击。

### 杀毒软件或系统提示拦截

未签名程序可能被杀软误报，甚至直接隔离。处理顺序：

1. 先确认安装包来源可信，并核对 SHA256（见第 1 步）。
2. 在杀软里把被隔离的文件**恢复**，把程序目录（默认 `D:\LiuHao`，回退时 `%LOCALAPPDATA%\Programs\LiuHao`）加入信任或排除。
3. 重新运行安装包或重新启动程序。

不要为了安装关闭整个杀软的实时防护。公司电脑被安全策略锁定时，联系 IT 放行。

如果被拦的是 `runtime\python.exe`，现象通常是双击后黑窗口一闪就没了。恢复这个文件并加信任后再启动。

### 安装失败常见原因

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 启动时黑窗口出现 `[warn] ... 已自动改用 NNNN`，或浏览器打不开 `8080` | `8080` 被别的程序占用。程序会自动换端口，这不算安装失败 | 按黑窗口打印的端口访问；或先关掉占用 `8080` 的程序再启动 |
| 提示“权限不足 / 拒绝访问” | 目标目录不可写（D 盘只读、被策略限制），或公司电脑禁止安装软件。具体提示与回退位置以安装器「准备安装」页为准 | 让安装器回退到用户目录（默认会自动回退，无需管理员权限）；公司电脑找 IT 放行 |
| 重复安装失败，或提示文件被占用 | 旧版本还在运行。安装器**不会**自动关闭正在运行的程序 | 先退出鎏灏：托盘菜单“退出”，或关掉黑色窗口；再运行安装包。安装器 `AppId` 固定，覆盖安装即可，数据目录不受影响 |
| 双击没反应 | 被 SmartScreen 拦住，或安装包被“锁定” | 按上面的“更多信息 → 仍要运行”；或右键属性 → 勾选“解除锁定” |
| 黑窗口一闪而过 | 程序没装完整，或 `runtime\python.exe` 被杀软隔离 | 重新安装；把程序目录加入杀软信任；仍不行看数据目录下 `logs` 与 `diagnostics` 里的记录（具体路径见程序目录 `data-dir.txt`） |
| 安装包明显偏小，或文件名以 `.crdownload` 结尾 | 下载没完成 | 重新下载，并核对发布页的 SHA256 |

### 中文或空格路径：已实测可用

安装目录可以包含中文和空格。实测路径：`D:\测试 路径\鎏灏`。

- 静默安装耗时 24～25 秒，装出 10,502 个文件、170,666,366 字节（0.1.0 交付包实测；体积会随版本变化，以发布页为准）。
- 连续两次安装后，逐字节一致。
- 桌面和开始菜单快捷方式正常。
- 双击快捷方式可启动：网关就绪 3.58 秒，控制台页面（驾驶舱）返回 HTTP 200；先打印“鎏灏已就绪”，再打开浏览器。`/v1/startup` 到达 `ready`，`GET /` 返回 200。
- 安装树自带的升级检查在中文路径下返回 `up_to_date`，不会出现 `version_unknown`。

程序文件与用户数据是分开的：

- 正常安装后，程序目录里没有数据库、日志、`app.env`；日志写到数据目录。
- 用户数据默认落在 `D:\LiuHaoData`（回退时 `%LOCALAPPDATA%\LiuHao\data`），实际位置见程序目录 `data-dir.txt`，可用 `LIUHAO_DATA_DIR` 覆盖。
- 数据目录本身也可以放在中文路径。
- 日志按 UTF-8 写入数据目录 `logs\liuhao.log`；中文显示正常，实测 0 个替换字符，无编码异常。

**已修复并复核**：干净安装 + 一次真实首启后，程序目录新增文件 0、新增目录 0；没有 `logs\`，也没有 `__pycache__`。

## 数据在哪里、怎么备份

所有用户数据都在：

`D:\LiuHaoData`（回退时 `%LOCALAPPDATA%\LiuHao\data`）

程序目录默认 `D:\LiuHao`（回退时 `%LOCALAPPDATA%\Programs\LiuHao`）。
覆盖安装和升级只替换程序目录，不动数据目录。
运行 `LiuHao.bat` 时以程序目录下的 `data-dir.txt` 为准，不要凭记忆猜路径。

### 备份（界面按钮或手动复制）

登录后可用 **系统设置 → 备份与迁移**（仅根账号可见）导出/恢复备份。
没有界面条件时，手动复制整个数据目录最稳：

1. 先退出鎏灏：托盘菜单“退出”，或关掉黑色窗口。
2. 打开程序目录的 `data-dir.txt`，按里面记录的路径打开数据目录。
3. 把整个数据文件夹复制到 U 盘、移动硬盘或另一块磁盘。
4. 恢复时，先退出鎏灏，再把备份覆盖回同一位置。

注意：数据目录里还有一个 `data` 子文件夹，里面的 `model_config.key` 和 `model_registry.sqlite3` 必须一起备份。缺一个，已保存的 API Key 就解不开。

### 两条打包路线：界面导出 vs CLI 备份

「备份与迁移」页面里的导出和命令行备份**不是同一个东西**。它们各自能带走什么，
请按用途选，不要以为随便一个包都能换机登录。

| 内容 | 界面「导出备份」`.json` | CLI 明文备份 | CLI 加密备份 `.lhbak` |
| --- | --- | --- | --- |
| 账号树、账号与登录密码 | 带 | 不带 | 带 |
| 成员、员工、目标、记忆、会话 | 带 | 带 | 带 |
| 知识库、工作区文件/工件 | 带 | 带 | 带 |
| 主账号模型 Key | 带（口令保险箱，包里无明文） | 不带 | 带 |
| 成员模型 Key | 带（口令保险箱；整树导出才有） | 不带 | 带（整机快照） |
| 登录凭据（密码哈希，用于原密码登录） | 带（仅口令包内） | 不带 | 带 |
| 本机身份库文件 `human_identities.json` | **不带**（只导出可重建的账号记录） | 不带 | 带 |
| 身份签名密钥 `integrity.key` | **不带** | 不带 | 带 |
| 模型主密钥 `model_config.key` | **不带** | 不带 | 带 |
| 凭据库文件 `auth_secrets.json` | **不带** | 不带 | 带 |
| 服务密钥 `app.env` | **不带** | 不带 | 带 |
| 换机后能否直接登录、Key 不用重填 | 能 | **不能登录** | **能** |

说明：

- 界面导出**刻意不带**本机身份库文件、身份签名密钥、凭据库文件和模型主密钥。
  这是产品承诺，不是 bug：它们只在本机有意义，带出去等于把整台机器的信任根
  交出去。换机所需的账号记录与 Key 密文另用口令保险箱封装，包里没有明文。
- CLI 明文备份也不带这些文件，所以它只适合"数据留档"，**不能**换机登录。
- 要完整换机（连同身份库、主密钥），只有两个选择：**CLI 加密备份 `.lhbak`**，
  或**退出程序后整目录冷拷贝**。加密包是整机快照，成员 Key 也在里面，
  请像保管密码一样保管它。

命令行（在程序所在目录执行，先把数据目录和备份目录指对）：

```bat
set LIUHAO_DATA_DIR=D:\LiuHaoData
set LIUHAO_BACKUP_DIR=D:\LiuHaoBackups

REM 导出并加密（必须给口令；加密包才带身份库/主密钥）
python -m src.cli backup create --encrypt --password "你的口令" --description "换机"

REM 在新机器上恢复到空目录（目标目录必须为空）
python -m src.cli backup restore <backup_id> --password "你的口令" --target D:\LiuHaoData
```

恢复会把 `config\`、`memory_store.db`、`data\`、`workspace\` 按真实布局铺开；
目标目录只要已含这些内容就会被拒绝，避免把两份数据拼在一起。恢复成功后，
让程序使用这个目录（把路径写进 `data-dir.txt`，或设置 `LIUHAO_DATA_DIR`），
再按 `config\current_url.txt` 打开驾驶舱，用原账号登录即可继续派活。

### 口令丢了怎么办（没有后门）

- **界面导出的 `.json`**：口令只用来解包，文件里没有口令。口令丢了，这个包就
  打不开；已导入到新机盘的账号不受影响。唯一出路是**回旧电脑用同一版本重新导出**
  （前提是旧电脑的数据还在）。
- **CLI 加密包 `.lhbak`**：口令经 PBKDF2-SHA256（20 万次）派生密钥，再用
  AES-256-GCM 加密。**没有万能口令、没有管理员找回、没有"跳过口令"开关。**
  口令丢失只能回源机重新导出；源机数据也丢了，就只剩明文备份里的非密钥数据。
- `LIUHAO_BACKUP_PASSWORD` 只是省得每次输口令的传参方式，不会写进包、不会写日志。
  不要把口令和备份包放在同一个 U 盘/同一台机器上。
- 错口令、缺口令、包被截断都会**在写盘前**失败，并给出中文原因；恢复目标目录
  保持为空，不会留下"恢复了一半"的数据。

### 实测：加密备份的耗时与体积

在 Windows 开发机、`python -m src.cli`、同一块 SSD 上实测（数据来自验收脚本）：

| 数据目录 | 加密包 | 导出（快照+编码） | 加密（AES-256-GCM） | 恢复（解密+铺开） |
| --- | --- | --- | --- | --- |
| 5.4 MB / 26 文件 | 0.2 MB | 1.5 秒 | 0.15 秒 | 1.1–3.3 秒 |
| 13.3 MB / 30 文件 | 11.0 MB | 1.7 秒 | 0.5 秒 | 1.1 秒 |
| 37.5 MB / 30 文件 | 43.3 MB | 5.4 秒 | 1.8 秒 | 2.8 秒 |

- 包体积主要跟数据本身有关：文本/JSON 压得很好（5.4 MB → 0.2 MB）；
  已经是随机/压缩内容（示例里的大文件）基本不压，包会和数据一样大。
- 恢复时间包含解密、解压、按布局落盘；口令派生有约 0.1 秒固定开销。
- 复现命令：`python scripts/acceptance/cli_backup_restore_e2e.py`
  （默认额外造 32 MB 大文件；`LIUHAO_E2E_BIG_MB=0` 可只跑真实小数据）。

不会。关掉黑色命令行窗口只是停止服务；下次双击快捷方式重新启动，账号、Key、聊天记录都会保留。

## 怎么彻底卸载（卸载默认保留数据）

1. 打开 **设置 → 应用 → 已安装的应用**，找到“鎏灏 LiuHao AI OS”，点卸载。
2. 卸载器先删程序，然后问你是否同时删除数据。**默认是“否”**。
3. 想保留账号、Key 和聊天记录：选“否”。以后重装，这些还在。
4. 想彻底删除：选“是”，卸载器还会再确认一次。**两次都确认**才会删除 `data-dir.txt` 记录的数据目录（默认 `D:\LiuHaoData`，回退时 `%LOCALAPPDATA%\LiuHao\data`），删除后无法恢复。
5. 卸载完成后，如果数据目录（`D:\LiuHaoData`）或回退目录 `%LOCALAPPDATA%\LiuHao` 还在，确认不需要后再手动删除。
6. 如果开过开机自启，到 **任务管理器 → 启动** 里确认 `LiuHaoAIOS` / `pythonw.exe` 项已经消失；还在就右键禁用。

一句话记住：**卸载默认会保留数据；只有你明确选了“删除数据”，才会真的删。**
