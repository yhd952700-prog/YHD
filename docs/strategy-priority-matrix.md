## 2. 现在不该做的 13 项（逐项一句理由）

### 2.1 仅设计，不实现（5 项）

- **4 自主研究与科学发现**：仓库零实现，需要常驻外部检索与论文源，收益取决于不可控的外部内容，先只设计状态机与安全边界。
- **13 云端与边缘计算**：默认形态是单进程单端口、不依赖 Docker，常驻云/边缘与“双击即用、无需运维”直接冲突，只设计可选出口。
- **21 分布式系统**：产品是单机单进程，现有协调模块只服务于执行围栏，没有多节点部署与集群调度 API，先只设计一致性契约。
- **25 开源技术情报**：CLI + SQLite 已可用但属低频开发者工具，且快照已过期，产品化收益低于维护成本，保留 CLI 即可。
- **27 隐私计算与可信 AI**：策略库存在但未接写入路径，MPC/TEE 需要多方或特殊硬件，单机做不出真实隐私计算，先把 PII 强制点设计清楚。

### 2.2 明确不做（8 项）

- **6 电脑自主操作**：三闸默认关闭、唯一后端是 `fake.py`，放开等于把 OS 权限交给未验证执行器，安全与不可运维故障面不可接受。
- **10 数字孪生与仿真**：需要物理模型、传感器与仿真环境，单机产品没有数据输入源。
- **11 物联网**：需要 MQTT/Modbus/OPC-UA 设备与 7×24 现场运维，超出个人单机范围。
- **12 机器人与具身智能**：安全关键作动需要硬件、实时性保障与安全认证，不可由本产品承担。
- **14 空间智能**：需要 GIS/点云/3D 数据与 GPU，个人单机没有输入源。
- **15 工业自动化**：需要 PLC/SCADA 与真实产线，法律与安全责任不可承担。
- **18 个性化教育**：38 个行业模板只被测试导入，没有学生模型、课程体系与进度数据，做出来只是模板 Demo。
- **19 创意生产**：顶层插件未加载，没有 TTS/STT/图像生成执行路径，生成依赖 GPU 或云 API，与成熟工具竞争无胜算。

## 3. 判定口径

### 3.1 四列怎么判

| 列 | 三档/取值 | 判据 |
|---|---|---|
| 能不能做 | 可行 / 有条件可行 / 不可行（本产品） | **可行** = 非测试生产代码中存在真实模块且能追到调用方或真实后端（对应原报告 §6 四关）；**有条件可行** = 存在模块但缺产品面，或缺外部硬件/GPU/密钥；**不可行** = 零实现且缺必要输入，或安全/法律责任不允许。**“可行”不含运行时验证** |
| 值不值得做 | 高 / 中 / 低 | **高** = 不新增外部依赖就能显著提升“双击→填 Key→能用”；**中** = 需额外配置/资产，或只提升局部环节；**低** = 对单个本地用户无日常价值，或需要用户不具备的硬件/运维 |
| 依赖顺序 | 方向编号 + 模块/配置前置 | 只写“必须先完成什么”，不写工期；前置条件全部来自原报告 §1 现状矩阵与 §3 路线图 |
| 最早可开始 | 现在 / 下一阶段 / 不现在做 | **现在** = 无阻塞依赖且直接服务主线；**下一阶段** = 依赖“现在”项完成，或需要额外 Provider/资产配置；**不现在做** = 缺硬件/外部服务/安全法律风险，或只保留设计 |

### 3.3 属于推断、不是代码事实的判断

- **“值不值得做”整列**：全部是价值判断，不是代码可证明的事实；依据是主线目标与单机产品形态，不是运行数据。

- **“不现在做”的理由**：除文件路径与缺口属证据外，“收益低于维护成本”“与主线无关”“法律责任不可承担”均为判断。
- **方向 4/10/11/12/14/15 的“零实现”**：来自关键词与目录检索，原报告 §5.13 已声明未逐个人工通读 433 个 `src/*.py`，不排除其他命名下的隐藏实现。
