# 规格卡 · 经典主题工作台（桌面）

上级：SPEC-总册。状态：V1.5 试点卡（2026-11-18 立）。实现载体：wb 壳 +
经典主题叠加层（`console/theme/jarvis-theme.{js,css}`）；不重建 dist。

## 1. 布局结构

- 顶栏：与未来主题同一瘦身口径（搜索 / 低调状态 / 主题切换 / 安静 /
  铃铛），见总册 T-01。
- 左栏：Bot 栏（贾维斯卡 + Bot / 群聊列表 + 新建入口提示）、底部 Boss 卡
  （账号名 + 我的工作空间 + 待办角标）。
- 主区：对话流 + 建议胶囊行（可横滑）+ composer（一行化）。
- Boss 面板（工作区总览）：入口网格，留白按 8pt 体系，不挤不贴边。

## 2. 状态

- 空：主区空态给建议胶囊与一句话引导，不留大片无说明空白。
- 加载 / 出错 / 待审批：与未来主题同口径（人话、低调状态条、角标计数）。
- 语音：经典主题**没有中央语音钮**——composer 的「按住说话」钮与
  「朗读音色」下拉是经典主题的语音入口，**保留显示**（F-01 只管未来
  主题）；状态反馈以钮上文案与消息区文字为准。

## 3. 断点行为

- 桌面（>480px）：本卡布局。≤480px 转手机端卡。

## 4. 显示 / 隐藏清单

显示：composer 一行（＋ / 输入 / 发送 / 按住说话）、朗读音色下拉、
胶囊行（横滑）、Boss 卡、网格入口。
隐藏（不许出现）：顶栏「下载桌面版」按钮（移入设置 / 关于）；独立
ONLINE 徽标与 UTC 时钟（收成低调状态一条）；任何内部串 / 错误码。

## 5. 间距与字阶（双主题同表，C-02）

- 间距基数 8pt：4 / 8 / 16 / 24 / 32；面板内边距 16，网格间隙 16。
- 字阶：标题 20 / 区块题 15 / 正文 14 / 辅助 12；行高 1.5。
- 未来主题同表执行（其卡 §1 已引用本节）。

## 验收点（V1.5 按卡对）

桌面截图（改前 / 改后）：composer 一行不折行、胶囊行可横滑、Boss 网格
留白达标、顶栏五件套；黑名单扫描零命中。
