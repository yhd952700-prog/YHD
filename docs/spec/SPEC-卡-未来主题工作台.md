# 规格卡 · 未来主题工作台（桌面）

上级：SPEC-总册。状态：V1.5 试点卡（2026-11-18 立）。实现载体：wb 壳 +
未来主题叠加层（`console/theme/jarvis-future-theme.{js,css}`）；不重建 dist。

## 1. 布局结构

- 顶栏（瘦身后）：左 = 搜索框；右 = 低调状态一条（连接状态 + ONLINE 合并
  显示）、主题切换（未来 / 经典）、安静、铃铛（通知角标）。仅此五件。
- 左屏（玻璃）：聊天面——Bot 对话流、建议胶囊行、composer。
- 中央：小铁全息像 + 中央语音钮（声波条 + 状态文案），全站唯一语音入口。
- 右屏：页签「数据 / 我的空间」——数据 = 今日小结、贾维斯的电脑等状态卡；
  我的空间 = 入口网格（日常 8 / 全部 27 切换）。
- 8pt 间距体系；字阶与经典主题同表（见经典卡 §5）。

## 2. 状态

- 空（新账号）：左屏显示建议胶囊四枚（查天气 / 写邮件 / 记提醒 / 建 Bot）
  + 「知道了」；右屏今日小结显示「今天没有待办。」。
- 加载：状态以顶栏低调状态条为准（已连接 / 连接中 / 已断开），不弹原始
  错误；断开时聊天区给人话提示与重试入口。
- 出错：一切错误人话化（总册负面清单 3）；例：电脑操控不可用只说
  「这台电脑不是 Windows，电脑操控不可用。」不带任何括号内码。
- 待审批：通知角标计数 + 我的空间角标计数；点开进待办审批面处理。
- 语音四态（中央钮）：聆听（声波动画 +「正在聆听」）/ 已唤醒（「我在呢，
  请说」）/ 识别·思考（「正在识别 / 思考中」）/ 播报（暖色声波 +「正在
  播报」）；安静模式下动画冻结。状态源 = `GET /v1/voice/status` 的
  session.state（V1）。

## 3. 断点行为

- 桌面（>480px）：本卡布局。≤480px 转手机端卡（中央语音区让位给
  composer 语音钮，见手机端卡 §3 的断点裁决）。

## 4. 显示 / 隐藏清单

显示：搜索、低调状态、主题切换、安静、铃铛；中央语音钮（四态）；
composer 的 ＋（青蓝）、输入框、发送；胶囊行；接着昨天的（有历史时）。
隐藏（不许出现）：composer 的「按住说话」钮、「朗读音色」下拉及其整行
（F-01）；顶栏的「下载桌面版」按钮（T-01，移入设置 / 关于）；独立的
ONLINE 徽标与 UTC 时钟（T-01，收进低调状态）；铜色 ＋（F-02）。

## 5. 用户可见文案清单（要点）

- 语音状态文案：正在聆听 / 我在呢，请说 / 正在识别 / 思考中 / 正在播报 /
  按住说话（中央钮待机文案）。
- 失败人话（V1 人话层）：没听清，请再说一次 / 语音识别还没装好… /
  语音播报还没装好，这次先看文字吧（以 `src/voice/session.py` 人话表为准）。
- 禁止出现：任何 `*_unavailable:` 类内部串、英文报错原文、调试计数。
