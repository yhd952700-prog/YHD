## B. 能力（27 Boss 项 + 系统能力）

枚举方法：Boss 27 项以包内「全部 · 27」网格实测名单为准逐项登记；
系统能力以下列清单为底（V4 逐项核对增删）。

系统能力底单：语音（唤醒 / 识别 / 合成 / 会话状态机）、提醒（含提前量，
V2）、晨间简报（含播报，V2）、Web Push（V2）、同步（U5）、自动更新
（U2）、备份与恢复（U6 账号包 + V10 加密云备份）、技能与技能包（V7）、
多 Bot 协作（V8）、成本智能路由（V9）、模型故障转移（U1）、电脑操控
（自动化闸门）、知识库（V6 向量链路）、记忆、主动管家（U4 例程）、
设备 / PWA（U5 季线 + V3 TWA）。

已有规格出处示例：语音 → 总册 F-01 + V1 报告节 + docs/voice 文档；
更新 → U2 交接 + V5 manifest 纪律（待 V5 落地回填）。

## C. 数据类

账号包（导出 / 导入格式与范围）、知识（文档 / 向量索引）、记忆
（长期记忆 / 会话）、对话与任务（会话库 / 提醒库）、语音资产（模型 /
音色设置）、推送订阅（V2）、备份快照（V10）、技能包数据（V7）。
逐项登记：格式、存放、保留策略、迁移 / 恢复口径、规格出处或补卡。
