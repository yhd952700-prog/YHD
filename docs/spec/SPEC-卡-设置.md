# 规格卡 · 设置（含关于）

上级：SPEC-总册。状态：V1.5 试点卡（2026-11-18 立）。本卡先立目标口径；
内部分区细节以现行包内实况为准，V1.5 施工前实机逐区核对、与卡不符先
改卡再施工（总册 §3 先卡后工）。

## 1. 布局结构

- 左侧分区导航 + 右侧分区内容（桌面）；手机端转单列（分区导航变顶部
  横滑条），见手机端卡。
- 分区（目标口径）：账号与恢复 / 模型 Key / 语音对话 / 通知 / 数据与
  备份 / 关于。
- 「关于」承接顶栏移出的「下载 Windows 桌面版」入口（T-01）：版本、
  下载桌面版、检查更新同区陈列。

## 2. 状态

- 空：未配模型 Key 时，模型 Key 区显示「还没配 Key」人话空态 + 一句
  聊天口径指引（「在聊天里说：帮我配模型 Key」）。
- 加载：分区切换不白屏；保存中按钮转忙态。
- 出错：保存失败给人话原因与重试；Key 只显示尾号掩码，永不回显明文
  （总册负面清单 4）。
- 待审批：不适用为本面主状态；与审批相关的开关（如离线许可证）在本面
  只做开关与状态展示，审批动作回工作台待办面。

## 3. 断点行为

- 桌面：双列（导航 + 内容）。412 / 390 / 360：单列，导航横滑，表单
  控件触控 ≥44px，开关行整行可点。

## 4. 显示 / 隐藏清单

显示：语音对话区承接音色 / 语速 / 音量（F-01 的功能落点，与 composer
退场的朗读音色同一设置源）；通知区承接推送总开关（V2 落地后在此
登记，默认关）；关于区承接下载桌面版。
隐藏（不许出现）：内部路径、环境变量名、原始错误码、英文内部串；
任何位置不显示完整 Key / 令牌。

## 5. 用户可见文案清单

- 分区名只用人话：账号与恢复 / 模型 Key / 语音对话 / 通知 / 数据与
  备份 / 关于。
- 语音对话区说明沿用现行口径：「语速、音量在这里调」（composer 提示
  与之同源）。

## 验收点（V1.5 按卡对）

桌面 + 412 截图：关于区可见下载桌面版入口且顶栏已无该按钮（与工作台
卡联验）；语音对话区可见音色设置；黑名单扫描零命中。
