## C. 数据类

| 数据类 | 格式 / 存放 | 保留与迁移口径 | 出处 |
|---|---|---|---|
| 账号与凭据包 | 口令信封（PBKDF2-SHA256 200k → AES-256-GCM）导出文件 | 手动迁移；导入 INSERT OR IGNORE 不覆盖现场 | 打磨第四轮报告 + V10 节（同信封） |
| 知识文档与向量索引 | 文档原件 + 本地 ONNX 向量（bge-small-zh-v1.5） | 随账号包迁移（原件过大只迁元数据/分块，已披露） | 季报 V6 节 + 第四轮报告 |
| 长期记忆（含修订） | 结构化存储 + 修订历史 | 随账号包迁移 | `docs/MEMORY-SYSTEM-DESIGN.md` |
| 会话 / 任务 / 目标 | 本地库（数据目录） | 随备份/账号包；同步面走 U5 冲突口径 | S1 季报 U5 节 |
| 提醒库 | SQLite（lead_minutes 列，旧库自动迁移） | 随数据目录备份 | 季报 V2 节 (a) |
| 语音资产 | 引擎模型（本地）+ 音色/语速设置 | 模型不随包（首用下载）；设置随账号包 | 季报 V1/V2 节 |
| 推送订阅 | `<数据目录>/push/subscriptions.json`（0600，VAPID 私钥同级 0600） | 不迁移（换机重新订阅）；失效端点自动清理 | 季报 V2 节 (c) |
| 备份快照（V10） | 凭据包同格式 + sidecar 元数据（无内容无口令） | 默认滚动保留 5 份（1–100 可调） | 季报 V10 节 |
| 技能包数据 | zip/目录 + 注册表记录（author/dependencies） | 随数据目录；升级使旧授权失效 | `docs/skill-package-format.md` |
| 审计链 | SQLite + 哈希链（检查点密钥机器绑定） | 不随账号包迁移（有意：链与机器绑定） | 第四轮报告（边界条） |
