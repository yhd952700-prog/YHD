# 规格卡 · 登录页（含首次设置）

上级：SPEC-总册。状态：V1.5 试点卡（2026-11-18 立）。实况基线：登录页由
网关随控制台一同下发，主题叠加层在登录页生效（实测 body 带主题标记、
叠加 JS/CSS 可达登录 DOM）——故 L-01 全部条目按「叠加层可达」施工；
施工时逐项复核选择器，若某项确不可达，立即停该项、把精确改动清单转
入 V4 对齐范围并在本卡标注，不许重建 dist。

## 1. 布局结构

- 居中单卡：小铁 logo（替换现有文字标）→ 标语一句 → 表单 → 主按钮 →
  辅助链接行（忘记密码 · 下载桌面版文字链）。
- 登录态：页签「登录 / 创建账户」；输入：账号、密码；记住我勾选；
  主按钮「登录」。
- 首次设置态（本机无账号）：标题「首次使用 · 初始化本机」+ 一句人话
  说明；输入：账号、显示名（可选）、密码、确认密码；可选勾选「同时
  配置模型 Key」；主按钮「创建并进入系统」；创建成功后展示恢复码一次
  （复制 / 下载恢复材料 / 我已保存）。

## 2. 状态

- 空：登录态默认聚焦账号框。
- 加载：主按钮转忙态文案，不许白屏。
- 出错：密码错 / 账号不存在等人话提示贴在表单上方；不许出现内部错误
  串、HTTP 码、堆栈字样。
- 待审批：不适用（登录前无审批面）——本项裁决：不立条目，理由如前。

## 3. 断点行为

- 桌面与 412 / 390 / 360 同一单卡布局，卡片宽度自适应（边距 ≥16px），
  触控目标 ≥44px；不出现横向滚动。

## 4. 显示 / 隐藏清单

显示：小铁 logo、标语、表单、主按钮、忘记密码、下载桌面版（低调文字
链样式，非按钮）。
隐藏（不许出现）：「网页版」按钮（网页端上无意义，L-01）；底部调试
小字整段——「已登记账号：N · 可登录：N · 会话有效期：N 小时」；
任何内部计数 / 配置外露。

## 5. 用户可见文案清单

- 标语（简化后）：「你的 AI 工作台，随身带着走。」（一句，不许出现
  「全栈 AI 智能中枢 · 统一入口」类开发话，也不许出现「三端共用同一
  会话，权限判断始终在服务端完成」类实现说明）。
- 同意行（简化后）：「登录即代表同意以同一账号在各端使用。」
- 首次设置说明（简化后）：「这台机器还没有账号。先创建你的账号，
  创建好会给你一份恢复材料，请收好。」

## 验收点（V1.5 按卡对）

桌面 + 412 截图（改前 / 改后）逐项对 §4；以未登录状态与首次设置状态
各验一遍；黑名单扫描对登录页文案零命中。
