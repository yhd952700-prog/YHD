# 规格卡 · 手机端（双主题，≤480px）

上级：SPEC-总册。状态：V1.5 试点卡（2026-11-18 立）。原则：手机端是
**单列聊天优先的独立布局，不是桌面缩放**（M-01）。

## 1. 布局结构（自上而下）

1. 顶栏（瘦身）：小铁头像 + 「贾维斯」+ 铃铛（角标）。仅此三件——搜索、
   主题切换、安静、状态收进「设置」或数据屏，不上手机顶栏。
2. 聊天区（单列，占满主屏）：对话流 + 胶囊行（横滑）。
3. composer（一行）：＋ / 输入 / 发送 / 语音，四件一行不折行。
4. 底部导航（4 项）：贾维斯 / 任务 / 空间 / 设置。
5. Bot 栏 = 抽屉：默认隐藏；点头像（顶栏小铁）或左缘滑出，内含 Bot /
   群聊列表与新建入口；选中后自动收起。

## 2. 状态

- 空：聊天区显示建议胶囊（同桌面文案）。
- 加载 / 出错：同双主题工作台口径（人话、低调提示），不弹内部串。
- 待审批：铃铛角标 + 任务页内列表承接；底部导航「任务」可带角标。
- 抽屉：打开时聊天区压暗、点空白处收起；抽屉内触控目标 ≥44px。

## 3. 断点行为

- 412 / 390 / 360 三档同一布局，仅间距按 8pt 体系微调；三档各验。
- >480px 回桌面布局（两张工作台卡）。
- **语音入口断点裁决**：桌面未来主题 = 中央语音钮唯一入口（F-01）；
  手机端中央全息区不占屏，composer 行内的语音钮即手机端语音入口——
  同一面（手机布局）内仍只有一个语音入口，不违反负面清单 2。
  经典主题手机端同此（其桌面本就以 composer 语音钮为入口）。

## 4. 显示 / 隐藏清单

显示：顶栏三件、底部导航 4 项、composer 四件、抽屉（按需）。
隐藏（不许出现）：桌面式右侧数据屏（改为从「空间」进）、Bot 直列栏、
7 项底部导航（现行：企业总览 / 贾维斯 / 办公室 / 任务 / 知识 / 能力
中心 / 设置——收敛为 4 项）、顶栏的搜索框 / 主题切换 / 下载按钮 /
ONLINE 与时钟、「右键此处 · 新建分组」字样。

## 5. 用户可见文案清单

- 抽屉内新建分组提示：「长按新建分组」（替代「右键此处 · 新建分组」，
  且长按手势须真实可用：长按抽屉空白处触发新建分组）。
- 底部导航文案：贾维斯 / 任务 / 空间 / 设置。

## 验收点（V1.5 按卡对）

双主题 × 412 / 390 / 360 共 6 张改后截图（附改前同档位）：单列、无横
向滚动、composer 一行、触控目标实测 ≥44px（量最小控件）、抽屉开合
各一态；黑名单扫描零命中。
