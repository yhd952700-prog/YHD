# 首次使用信息披露审计（2026-11-08）

> 性质：只读审计，未改任何代码。  
> 对象：当前源码（0.1.1 开发态）+ 已构建交付物 0.1.0（`dist/installer/liuhao-0.1.0.zip`、`LiuHao-Setup-0.1.0.exe`）。  
> 方法：逐文件阅读安装器、首启向导、控制台前端、Key 存储与联网实现；对 0.1.0 便携包做只读解包核对（未解包 exe）。  
> 目标：回答三个问题——**数据在哪 / 会不会上网 / 怎么卸载干净**，并检查隐私入口、同意阻断、中文表述。

## 一、结论先行：装完后用户能不能自己回答三个问题

| 问题 | 结论 | 依据（用户实际能看到的） |
|---|---|---|
| **数据在哪？** | 🟡 **能，但依赖安装前那份文本，控制台里查不到** | 安装器「安装前必读」第 2 条、`START-HERE.txt`、程序目录 `data-dir.txt`、0.1.1 图形向导第 1 步能看到；控制台 20+ 个导航项里没有任何「数据目录/存储位置」入口 |
| **会不会上网？** | 🔴 **不能** | 安装器、`START-HERE.txt`、命令行向导、图形向导、控制台界面**全部没有**「哪些内容会发到哪个服务商」的说明；只在申请 Key 处给了服务商网址 |
| **怎么卸载干净？** | 🟡 **能，但只在安装前和卸载时才知道** | 安装器「安装前必读」第 5 条写清「默认保留 + 两次确认才删」；卸载器交互也写清；控制台内没有卸载说明，卸载入口只在 Windows「设置 → 应用」 |

补充两句：

- **备份怎么做**：🔴 首启链路完全未提。控制台里的「备份与迁移」是**账号树加密备份**（仅根账号），不是整个数据目录备份；真正的「复制整个数据目录」只写在 `docs/END-USER-GUIDE.md`，而该文档**不随 0.1.0 包分发**。
- **数据是否加密**：🟡 只加密了 **API Key**；对话、知识库、记忆、审计是普通 SQLite/文件，未逐条加密。所有首启文案都只写「API Key 加密」，没有说明「其余数据不加密」，容易被理解成「整个数据目录已加密」。

### 0.1.0 与 0.1.1 的关键差异（影响用户实际看到什么）

| 关于/隐私/版本入口 | **没有**（控制台构建产物内「隐私/关于/许可证」字符串均为 0） | **没有** |

> 注：`dist/payload/app` 已是 0.1.1 暂存构建（`THIRD-PARTY-NOTICES.txt`、`licenses/`、`first_run_gui.py` 于 2026-11-07 13:29 生成），但 `dist/installer` 里仍是 0.1.0 的 exe/zip（11:13–11:14）。也就是说：**源码/暂存 payload 与用户手里的安装包不同步**，下面的「0.1.0 缺失」结论按实际 zip 实测，不按 payload 推断。

> 结论：**0.1.0 用户的首次披露 = 安装器一页文本 + 命令行向导 + START-HERE；控制台内没有任何数据位置 / 联网 / 加密 / 许可证 / 版本披露。** 0.1.1 源码把向导做漂亮了，但仍没补「上网 / 备份 / 加密边界 / 找谁」。

### 2.3 Key 的存储、加密、删除（代码事实核对）

| 事实 | 证据 |
|---|---|
| Key 密文存在数据目录的 `data/model_registry.sqlite3` | `src/ai/model_config.py:30-31`、`:57` |
| 加密算法 AES-256-GCM | `src/ai/model_config.py` 模块说明 + 密钥派生实现 `:303-324` |
| 解密密钥在**同一数据目录**的 `data/model_config.key` | `src/ai/model_config.py:22-23`、`:58`、`:651-661` |
| 该密钥文件会收紧为「仅当前 Windows 用户可读」的 DACL | `:318-324` 调用 `tighten_current_user_only` |
| 删除模型会连 Key 一起删 | `src/ai/model_config.py:820-828`（`DELETE FROM ai_model_configs`） |
| 没有独立的 Key 轮换/吊销接口 | `apps/console/console/src/pages/MyKeys.tsx:7-8` 明确写「没有 Key 的新增 / 轮换 / 吊销端点」 |
| 控制台删除确认只写「删除模型，不可撤销」 | `apps/console/console/src/components/ModelManager.tsx:443` |

**结论**：技术上「加密保存」属实；但披露缺三块——**密钥和密文放在同一个目录**、**只有 Key 加密**、**删除入口在「模型管理」而不是「我的 Key」**。
