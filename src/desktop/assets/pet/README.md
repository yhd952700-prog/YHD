# 桌宠图片资产说明（C-pet 组，0.4.6）

## 在用的：Joseph 原图转来的两帧

| 文件 | 来源 | 做法 |
| --- | --- | --- |
| `xiaotie-original-256-f0.png` | `apps/console/console/public/xiaotie-original-cut.webp`（Joseph 发的 Q 版小铁原图抠图，943×943） | 等比缩到 256×256，透明底原样保留，不改色、不重画 |
| `xiaotie-original-256-f1.png` | 同上 | 同一张图整体微转 2.5°＋上抬 3px（走路的另一只脚），不重画、不改色、不改身形 |

两帧交替＝走路节拍（桌宠档 0.45 秒一步，操作台框里是 CSS 的 0.9 秒），
脚下淡影跟着缩胀。原图是单张平面抠图、没有分开的手脚图层，所以手脚
没法逐根转——桌宠和操作台头像用的是同一套已批准的做法（整图起伏＋
淡影＋位置移动）；只有图片加载失败的 SVG 兜底（操作台）才有逐根摆动
的手脚。不要为了“手脚逐根动”去把原图切碎重画。

反应堆光晕位置按抠图版实测：x 59% / y 72%（与操作台 `XiaotieAvatar`
一致），颜色永远蓝色。
